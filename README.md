# 예배송출 (Worship Caster)

**노트북 한 대**(맥·윈도우)로 **예배당 TV/프로젝터(HDMI)** 와 **유튜브 생중계 자막(OBS)** 을 동시에 송출하는 교회 자막 프로그램입니다.

**만든 사람: 쉬운목사 이광복** · 무료로 나눕니다.

## 설치 (Node.js 등 따로 설치할 것 없음)
[Releases](../../releases) 에서 내 컴퓨터에 맞는 파일을 받으세요.

### 맥 — `예배송출-mac.zip` (애플 칩 M1~, 인텔 맥 모두)
1. 압축을 풀고 **예배송출.app** 을 '응용 프로그램' 폴더로 옮깁니다.
2. 처음 한 번만: 더블클릭 → "확인할 수 없습니다" 창에서 [완료] → **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 "예배송출" 옆 **[그래도 열기]**.
   (애플 유료 개발자 인증을 받지 않은 무료 프로그램이라 나오는 안내입니다)
3. 방화벽·"로컬 네트워크" 질문에는 **[허용]** (OBS 자막·웹 편집기에 필요).
4. 끌 때는 운영 화면 오른쪽 위 **⏻ 종료**. 자료는 `~/Library/Application Support/WorshipCaster` 에 저장됩니다.

### 윈도우 — `예배송출-windows.zip` (윈도우 10·11, 64비트)
1. 압축을 풀고 `예배송출` 폴더를 원하는 곳에 둡니다.
2. **예배송출 실행.cmd** 더블클릭. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행].
3. 방화벽 질문에는 **[액세스 허용]**. 엣지 창으로 운영 화면이 열립니다.
4. 작업 표시줄의 'WorshipCaster' 창이 프로그램 본체입니다(닫으면 꺼짐). 자료는 `%APPDATA%\WorshipCaster` 에 저장됩니다.

> 이미 켜져 있을 때 아이콘을 다시 누르면 운영 화면 창만 다시 열립니다. 인터넷 없이도 예배 진행이 됩니다.

## 주일 사용 순서
1. **노트북을 HDMI로 TV에 연결** → 운영 화면의 `📺 예배당 화면 열기` → 열린 창을 TV 화면으로 끌어다 놓고 `F` (전체화면)
2. **OBS 자막** → `🎥 OBS 자막 주소` 의 주소를 OBS **브라우저 소스**(1920×1080)로 추가하고 카메라 소스 위에 둠
   - 방송 PC가 윈도우여도 됩니다. 같은 공유기에 연결만 되어 있으면 됩니다. 캡처 장비·NDI 플러그인이 필요 없습니다.
3. 가운데 슬라이드를 **클릭하면 바로 송출**. 단축키: `→`/`Space` 다음, `←` 이전, `B` 검은화면, `C` 글자 지우기, `L` 로고, `Esc` 모두 끄기, `1~9` 슬라이드 바로 가기
4. 설교자·인도자용: `🎤 프롬프터 열기` (현재/다음 슬라이드 + 시계)

## 주중 준비 (웹 편집기)
집이나 사무실 컴퓨터 브라우저에서 `http://맥IP:5300/editor` → PIN 입력. PIN은 처음 실행할 때 6자리로 무작위로 정해지며, 운영 화면의 🎥 OBS 자막 주소 / ⚙︎ 설정에서 확인·변경합니다. 5번 틀리면 5분간 잠깁니다.
곡·말씀·광고·PPT·예배 순서·스타일을 준비할 수 있고, 송출 제어는 막혀 있습니다.
(운영 노트북이 켜져 있고 같은 네트워크여야 합니다)

## 자료 만들기
- **찬양**: ＋ 찬양 → 가사 붙여넣기 → "N줄씩 나누기". 빈 줄에서는 반드시 나뉩니다. ✂ 커서 위치에서 나누기, ⇣ 다음과 합치기
- **성경**: ＋ 성경 → `요 3:16`, `시 23:1-6`, `롬 8장`, `John 3:16`, `요한1서 1:9`. **함께 보일 번역본**을 고르면 한글·영어 같은 대역 슬라이드가 됩니다.
  - ⚙︎ 설정 → **성경 폴더**: 옵시디언 성경 폴더(`400_Bible`)가 등록되어 있습니다. 하위 폴더 `한글 (개역개정)` 같은 이름이 번역본 이름이 되고, 원본 파일은 읽기만 합니다. 각주(`| 주석:`)와 ①② 표시는 화면에서 뺍니다.
  - 기본 번역본은 개역개정입니다. 다른 텍스트 파일은 **성경 텍스트 가져오기**로 넣을 수 있습니다.
  형식: `창1:1 본문…` 또는 `창세기<TAB>1<TAB>1<TAB>본문` (UTF-8/EUC-KR). 개역한글은 저작권이 만료되었고, 개역개정·새번역은 대한성서공회 라이선스가 필요합니다.
- **PPT**: ＋ PPT → .pptx 선택. 글자·표·그림이 위치대로 들어오고 ✎ 편집에서 글자를 고치거나 그림을 바꿀 수 있습니다. (애니메이션·전환 효과는 가져오지 않음)
- **PDF·악보**: ＋ PDF·악보 → PDF 또는 악보 사진(jpg·png, 여러 장 가능). PDF는 페이지마다 슬라이드가 됩니다.
  악보는 "위·아래 2칸" 나누기를 쓰면 16:9 TV에서 크게 보이고, 흰 여백은 자동으로 잘라냅니다. 악보는 예배당 화면에만 나가고 OBS 방송 자막에는 나가지 않습니다.
- **배경**: 🖼 미디어에서 사진·영상을 올리고, 편집기의 🖼 버튼으로 슬라이드 배경을 지정 (영상은 소리 없이 반복)

## 화면 주소
| 주소 | 용도 |
|---|---|
| `/control` | 운영 (운영 노트북에서만) |
| `/output` | 예배당 화면 (HDMI) |
| `/overlay` | 방송 자막, 투명 배경 (OBS 브라우저 소스) |
| `/stage` | 프롬프터 |
| `/editor` | 웹 편집기 (PIN) |

## 개발자용
```bash
npm install && npm start      # 개발 모드 (자료는 ./data)
bash build-dist.sh            # 배포 파일 만들기 → dist/예배송출-mac.zip, dist/예배송출-windows.zip
bash build-dist.sh --install  # + 이 맥의 ~/Applications 에 설치
```
배포 파일에는 공식 Node.js(LTS, 체크섬 확인)가 함께 들어갑니다. 개발 명세는 [PROMPT.md](PROMPT.md).
