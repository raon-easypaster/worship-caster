# 예배송출 (Worship Caster)

맥북 한 대로 **예배당 TV/프로젝터(HDMI)** 와 **유튜브 생중계 자막(OBS)** 을 동시에 송출하는 교회 자막 프로그램입니다.
개발 명세는 [PROMPT.md](PROMPT.md)에 있습니다.

## 실행 (터미널 필요 없음)
- **예배송출.app** 을 더블클릭하세요. Launchpad나 Spotlight에서 "예배송출"로 찾아도 됩니다(`~/Applications`에 들어 있음).
  운영 화면이 크롬 앱 창(주소창 없음)으로 열립니다. 이미 켜져 있으면 창만 다시 엽니다.
- 끌 때는 운영 화면 오른쪽 위 **⏻ 종료** 를 누르세요.
- 기록 파일: `~/Library/Logs/예배송출.log`
- 프로그램 폴더를 옮겼다면 그 폴더에서 `bash make-app.sh` 를 한 번 실행해 앱을 다시 만드세요.
- 인터넷 없이도 예배 진행이 됩니다.

## 주일 사용 순서
1. **HDMI로 TV 연결** → 운영 화면의 `📺 예배당 화면 열기` → 열린 창을 TV 화면으로 끌어다 놓고 `F` (전체화면)
2. **OBS 자막** → `🎥 OBS 자막 주소` 의 주소를 OBS **브라우저 소스**(1920×1080)로 추가하고 카메라 소스 위에 둠
   - 방송 PC가 윈도우여도 됩니다. 같은 공유기에 연결만 되어 있으면 됩니다. 캡처 장비·NDI 플러그인이 필요 없습니다.
3. 가운데 슬라이드를 **클릭하면 바로 송출**. 단축키: `→`/`Space` 다음, `←` 이전, `B` 검은화면, `C` 글자 지우기, `L` 로고, `Esc` 모두 끄기, `1~9` 슬라이드 바로 가기
4. 설교자·인도자용: `🎤 프롬프터 열기` (현재/다음 슬라이드 + 시계)

## 주중 준비 (웹 편집기)
집이나 사무실 컴퓨터 브라우저에서 `http://맥IP:5300/editor` → PIN 입력(기본 `0000`, ⚙︎ 설정에서 변경).
곡·말씀·광고·PPT·예배 순서·스타일을 준비할 수 있고, 송출 제어는 막혀 있습니다.
(맥이 켜져 있고 같은 네트워크여야 합니다)

## 자료 만들기
- **찬양**: ＋ 찬양 → 가사 붙여넣기 → "N줄씩 나누기". 빈 줄에서는 반드시 나뉩니다. ✂ 커서 위치에서 나누기, ⇣ 다음과 합치기
- **성경**: ＋ 성경 → `요 3:16`, `시 23:1-6`, `롬 8장`, `John 3:16`, `요한1서 1:9`. **함께 보일 번역본**을 고르면 한글·영어 같은 대역 슬라이드가 됩니다.
  - ⚙︎ 설정 → **성경 폴더**: 옵시디언 성경 폴더(`400_Bible`)가 등록되어 있습니다. 하위 폴더 `한글 (개역개정)` 같은 이름이 번역본 이름이 되고, 원본 파일은 읽기만 합니다. 각주(`| 주석:`)와 ①② 표시는 화면에서 뺍니다.
  - 기본 번역본은 개역개정입니다. 다른 텍스트 파일은 **성경 텍스트 가져오기**로 넣을 수 있습니다.
  형식: `창1:1 태초에 하나님이…` 또는 `창세기<TAB>1<TAB>1<TAB>본문` (UTF-8/EUC-KR). 개역한글은 저작권이 만료되었고, 개역개정·새번역은 대한성서공회 라이선스가 필요합니다.
- **PPT**: ＋ PPT → .pptx 선택. 글자·표·그림이 위치대로 들어오고 ✎ 편집에서 글자를 고치거나 그림을 바꿀 수 있습니다. (애니메이션·전환 효과는 가져오지 않음)
- **PDF·악보**: ＋ PDF·악보 → PDF 또는 악보 사진(jpg·png, 여러 장 가능). PDF는 페이지마다 슬라이드가 됩니다.
  악보는 "위·아래 2칸" 나누기를 쓰면 16:9 TV에서 크게 보이고, 흰 여백은 자동으로 잘라냅니다. 악보는 예배당 화면에만 나가고 OBS 방송 자막에는 나가지 않습니다.
- **배경**: 🖼 미디어에서 사진·영상을 올리고, 편집기의 🖼 버튼으로 슬라이드 배경을 지정 (영상은 소리 없이 반복)

## 화면 주소
| 주소 | 용도 |
|---|---|
| `/control` | 운영 (이 맥에서만) |
| `/output` | 예배당 화면 (HDMI) |
| `/overlay` | 방송 자막, 투명 배경 (OBS 브라우저 소스) |
| `/stage` | 프롬프터 |
| `/editor` | 웹 편집기 (PIN) |

## 저장 위치
- `data/db.json` — 곡·예배 순서·스타일 (백업하려면 `data` 폴더를 복사)
- `data/media/` — 사진·영상, `data/bible/` — 성경 본문
