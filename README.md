# 예배송출 (Worship Caster)

**노트북 한 대**(맥·윈도우)로 **예배당 TV·프로젝터(HDMI)** 와 **유튜브 생중계 자막(OBS)** 을 함께 송출하는 무료 교회 자막 프로그램입니다.

**만든 사람: 쉬운목사 이광복** · 무료로 나눕니다.

📥 **다운로드**: [Releases](https://github.com/raon-easypaster/worship-caster/releases) — 맥은 `WorshipCaster-mac.zip`, 윈도우는 `WorshipCaster-windows.zip`
📖 **사용설명서**: [docs/사용설명서.md](docs/사용설명서.md) — 설치부터 주일 진행, OBS 연결, 문제 해결까지

## 할 수 있는 것
- **예배당 TV·프로젝터**: 노트북에 HDMI 선 하나
- **유튜브 생중계 자막**: OBS 브라우저 소스에 주소 하나 넣으면 카메라 화면 위에 자막이 투명하게 얹힘 (자막 보내는 데 캡처 장비·플러그인 불필요, 방송 컴퓨터는 맥·윈도우 상관없음). 예배 영상 자체는 OBS가 유튜브로 내보냅니다.
- **찬양**: 곡 제목으로 인터넷에서 가사를 찾아 프로그램 안에 바로 넣기 → 코드·[후렴] 표시 자동 정리 → "2줄씩" → 슬라이드 완성. 찬양만 자료실에 남고 말씀·광고는 예배가 끝나면 정리됨
- **성경**: `요 3:16`, `롬 8장`, `John 3:16` 입력 → 말씀 슬라이드, 두 번역 대역도 한 화면에
- **PPT·PDF·악보·HTML 가져오기**: 글자·그림 수정, 악보는 위아래로 나눠 크게, HTML 카운트다운 같은 움직이는 화면
- **예배 순서 템플릿**: 주일·성찬 주일·오후·찬양·수요·금요·새벽 예배 순서를 한 번에. "지금은 기도로 예배를 준비하는 시간입니다" 같은 문구, **성찬 예식**(제정의 말씀 포함)
- **움직이는 배경**: 은하수·물결·빛줄기·빛망울·오로라·새벽 하늘·촛불빛, 또는 내 동영상을 반복 재생 (켜고 끄기 버튼)
- **모양(테마)·글꼴**: 찬양·말씀·광고·기도·성찬 테마, 한글 글꼴 11종(프로그램에 내장, 인터넷 없이도 나옴), 예배당·유튜브 글자 크기 따로
- **로고**: 위치·크기 조절, 화면 구석에 늘 작게 띄우기(유튜브에도 가능)
- **곡 구성**: 1절·후렴·브리지 순서를 정해 후렴을 복사 없이 반복, 전체 글로 고치기, 오른쪽 클릭 빠른 수정
- **도구**: 타이머(예배 시작 카운트다운), 프롬프터에만 보이는 무대 메시지, 설교자 이름 자막, 광고 자동 넘김
- **휴대폰 리모컨**: 같은 와이파이 휴대폰에서 PIN으로 자막 넘기기
- **미디어 배경 칸**: 직접 만든 기본 배경 영상 5개 포함. 사진·영상을 한 번 누르면 예배당 화면 배경으로 계속 (슬라이드를 넘겨도 영상이 끊기지 않음), 맞춤·방송에도·삭제 안내
- **방송 바로 조절**: 그림을 방송에 화면 가득 / 화면 일부(6곳, 카메라 보이게) / 보내지 않기, 자막 위치·진하기
- **모니터 고르기**: 예배당 화면·프롬프터를 띄울 모니터를 골라 꽉 차게, 종료하면 창도 함께 닫힘
- **유튜브로 그림 보내기**: 광고 사진·악보는 유튜브에도 화면 그대로, 오른쪽 아래에 설교자 모습을 작게 (OBS 장면 자동 전환)
- **유튜브 자막만 따로 끄기**: 기도 제목·내부 광고는 예배당 TV에만 (버튼·O 키, 또는 자료별 설정)
- **프롬프터**: 설교자·인도자용 (지금·다음 슬라이드, 시계)
- **웹 편집기**: 주중에 다른 컴퓨터 브라우저에서 미리 준비 (같은 와이파이 + PIN)
- 인터넷이 없어도 예배 진행 가능

## 설치 (따로 설치할 프로그램 없음)
| 컴퓨터 | 방법 |
|---|---|
| 맥 (애플 칩 M1~ · 인텔) | 압축 풀기 → `예배송출.app` 을 응용 프로그램 폴더로 → 더블클릭. 처음 한 번 "확인할 수 없습니다"가 뜨면 **시스템 설정 → 개인정보 보호 및 보안 → [그래도 열기]** |
| 윈도우 10·11 (64비트) | 압축 풀기 → `예배송출 실행.cmd` 더블클릭. "Windows의 PC 보호"가 뜨면 **[추가 정보] → [실행]** |

방화벽·로컬 네트워크 질문에는 **[허용]** 하세요 (OBS 자막·웹 편집기에 필요). 자세한 내용은 [사용설명서](docs/사용설명서.md#2-설치하기)를 보세요.

## 성경 본문
성경 본문은 들어 있지 않습니다. 교회에서 사용할 수 있는 본문을 **⚙︎ 설정 → 성경 폴더** 또는 **성경 텍스트 가져오기**로 연결하세요. 형식은 [사용설명서 4장](docs/사용설명서.md#4-처음-한-번-해-둘-설정)에 있습니다.
개역개정·새번역·ESV·NIV 등은 저작권이 있으니 교회가 사용 허가를 받았는지 확인하세요. (개역한글은 저작권 만료)

## 개발자용
```bash
npm install && npm start      # 개발 모드 (자료는 ./data)
bash build-dist.sh            # 배포 파일 만들기 → dist/예배송출-mac.zip, dist/예배송출-windows.zip
bash build-dist.sh --install  # + 이 맥의 ~/Applications 에 설치
```
- 배포 파일에는 공식 Node.js 24 LTS(체크섬 확인)가 함께 들어갑니다.
- 구조: `server.js`(로컬 서버) · `lib/`(저장·성경·PPT 해석) · `public/`(운영·송출 화면)
- 화면 주소: `/control` 운영 · `/output` 예배당 · `/overlay` OBS 자막 · `/stage` 프롬프터 · `/editor` 웹 편집기 (포트 5300)
- 개발 명세: [PROMPT.md](PROMPT.md)
