## 1. 준비물

| 꼭 필요 | 있으면 좋음 |
|---|---|
| 노트북 1대 (맥 또는 윈도우 10·11) | 유튜브 방송용 카메라 + 무료 방송 프로그램 OBS (같은 노트북이어도, 다른 컴퓨터여도 됨) — HDMI 카메라는 캡처 장치 필요 ([8장](#8-유튜브-생중계에-자막-얹기-obs)) |
| TV·프로젝터와 연결할 HDMI 선 (맥은 USB-C→HDMI 젠더가 필요할 수 있음) | 같은 와이파이(공유기) — OBS를 다른 컴퓨터에서 쓰거나 웹 편집기를 쓸 때 |

- **인터넷이 없어도** 예배 진행은 됩니다.
- 이 노트북을 **운영 노트북**이라고 부르겠습니다. 자막을 넘기는 컴퓨터입니다.

## 2. 설치하기

받는 곳: **https://raon-easypaster.github.io/worship-caster/**
맥용·윈도우용 단추를 누르면 늘 최신 버전이 받아집니다. 설명서 PDF도 이 페이지에 있습니다.
따로 설치할 프로그램(Node.js 등)은 없습니다.

### 맥 (애플 칩 M1~ · 인텔 맥 모두)
1. **WorshipCaster-mac.zip** 을 받아 더블클릭해 압축을 풉니다.
2. **예배송출.app** 을 Finder 왼쪽의 **응용 프로그램** 폴더로 끌어다 놓습니다.
3. 예배송출을 더블클릭합니다.
4. **처음 한 번만** "확인할 수 없습니다"라는 창이 뜹니다.
   - [완료]를 누르고 → **시스템 설정 → 개인정보 보호 및 보안** → 맨 아래 "예배송출" 옆 <b>[그래도 열기]</b> → 다시 [열기].
   - 애플 유료 개발자 인증을 받지 않은 무료 프로그램이라 나오는 안내입니다.
5. "로컬 네트워크의 기기를 찾도록 허용" 또는 방화벽 질문이 나오면 <b>[허용]</b> 하세요.
6. 운영 화면이 열리면 설치 끝입니다.

### 윈도우 10·11 (64비트)
1. **WorshipCaster-windows.zip** 을 받아 오른쪽 클릭 → **모두 압축 풀기**.
2. 나온 `예배송출` 폴더를 문서 폴더 등 원하는 곳에 둡니다. (바탕화면에 바로가기를 만들어 두면 편합니다)
3. 폴더 안의 **예배송출 실행.cmd** 를 더블클릭합니다.
4. "Windows의 PC 보호" 창이 뜨면 <b>[추가 정보] → [실행]</b>.
5. 방화벽 질문이 나오면 <b>[액세스 허용]</b>.
6. 엣지 창으로 운영 화면이 열립니다.
   - 작업 표시줄의 **WorshipCaster** 창은 프로그램 본체입니다. <b>닫으면 프로그램이 꺼집니다.</b>

### 켜고 끄기
- **켜기**: 아이콘(맥) 또는 `예배송출 실행.cmd`(윈도우) 더블클릭. 이미 켜져 있으면 새 창을 열지 않고, 열려 있는 운영 화면을 앞으로 가져옵니다.
- 운영 화면(자막을 넘기는 창)은 **하나만** 씁니다. 실수로 두 개가 열리면 나중 창에 "이미 열려 있습니다" 안내가 뜹니다. 그 창에서 계속하려면 <b>[이 창에서 계속]</b>, 아니면 그 창을 닫으세요.
- **끄기**: 운영 화면 오른쪽 위 <b>⏻ 종료</b>. 예배당 화면·프롬프터 창도 함께 닫히고, OBS 자막은 비워집니다.
- 새 버전으로 바꾼 뒤 다시 켜면, 열려 있던 예배당 화면·OBS 자막 화면이 **스스로 새로고침**되어 새 버전으로 바뀝니다.

## 3. 화면 둘러보기

### 운영 화면

```
┌──────────────────────────────────────────────────────────────────────┐
│ ✝ 예배송출   [📺 예배당 화면 열기] [🎤 프롬프터 열기] [🎥 OBS 자막 주소] │
│              [🎨 자막 스타일] [🖼 미디어] [⚙︎ 설정] [⏻ 종료]          │
├──────────────┬────────────────────────────────┬──────────────────────┤
│ 예배 순서     │  선택한 자료의 슬라이드          │ 📺 예배당 화면 (주황)  │
│  ① 예배 준비  │  ┌────┐ ┌────┐ ┌────┐           │    A− 100% A+         │
│  ② 찬양       │  │ 1  │ │ 2  │ │ 3  │  ← 클릭하면 │ 🎥 방송 자막 (보라)    │
│  ③ 말씀       │  └────┘ └────┘ └────┘    바로 송출 │    ▸ 방송 바로 조절    │
│ 예배 순서에 넣기│                                │ 🎛 송출 조작 (파랑)    │
│  ＋찬양 ＋성경 │                                │  [◀ 이전] [다음 ▶]    │
│  ＋문구·성찬   ├────────────────────────────────┤  [■ 검은화면] [◻ 글자]│
│  ＋광고 ＋PPT  │ 🎞 미디어 배경                  │  [✝ 로고] [모두 끄기]  │
│  ＋PDF·악보    │  [영상][사진][영상] … 누르면     │  [🎥 방송 자막 끄기]   │
│  ＋HTML        │  예배당 화면 배경으로 계속 나옴   │  [👤 사람 화면][🌌 배경]│
│ 찬양 자료실    │                                │ ⏭ 다음 슬라이드 (초록) │
└──────────────┴────────────────────────────────┴──────────────────────┘
```

- **왼쪽**: 위는 오늘의 **예배 순서**, 가운데는 새 자료를 만드는 <b>＋ 버튼들</b>, 아래는 지금까지 만든 찬양이 모여 있는 **찬양 자료실**입니다.
- **가운데**: 고른 자료의 슬라이드들. <b>클릭하면 바로 화면에 나갑니다.</b> 지금 나가는 슬라이드는 빨간 테두리로 표시됩니다. 아래는 **미디어 배경** 칸입니다. ([7장 ⑤](#⑤-미디어-배경--영상사진을-배경으로-계속))
- **오른쪽**: 색 띠로 나눈 카드 4개 — **예배당 화면**(주황), **방송 자막**(보라), **송출 조작**(파랑), **다음 슬라이드**(초록). 예배당·방송 카드 제목 옆 <b>A− 100% A+</b> 로 글자 크기를 바로 바꿉니다.
- 맨 위 '예배송출' 앞의 ✝ 는 <b>⚙︎ 설정 → 타이틀 로고</b>에서 교회 로고로 바꿀 수 있습니다.

**크기 조절**
- **칸 너비**: 왼쪽·가운데·오른쪽 칸 사이의 **세로 경계선을 마우스로 끌면** 너비가 바뀝니다. 오른쪽 칸을 넓히면 미리보기가 커집니다. 경계선을 **두 번 누르면** 처음 너비로 돌아갑니다.
- **슬라이드·미디어 배경 높이**: 가운데 슬라이드와 아래 🎞 미디어 배경 사이의 **가로 경계선을 위아래로 끌면** 높이가 바뀝니다. 미디어 칸을 높이면 파일들이 여러 줄로 보입니다. 두 번 누르면 처음 높이로 돌아갑니다.
- **창 크기**: 운영 화면 창의 모서리를 끌어 크기를 바꾸면, 다음에 켤 때 **그 크기와 위치로** 열립니다.
- 바꾼 칸 너비는 이 컴퓨터에 기억됩니다. 창이 아주 좁으면(가로 1100px 아래) 경계선이 숨고 칸이 위아래로 놓입니다.

### 함께 쓰는 화면 4가지
| 화면 | 쓰는 곳 | 여는 법 |
|---|---|---|
| **예배당 화면** | TV·프로젝터 (HDMI) | 📺 예배당 화면 열기 |
| **방송 자막** | 유튜브 방송(OBS). 배경이 투명해 카메라 화면 위에 자막만 얹힘 | 🎥 OBS 자막 주소 |
| **프롬프터** | 설교자·인도자용 모니터. 지금 화면 + 다음 화면 + 시계 | 🎤 프롬프터 열기 |
| **웹 편집기** | 다른 컴퓨터에서 미리 준비 (송출은 못 함) | 🎥 OBS 자막 주소 창에 주소가 있음 |

## 4. 처음 한 번 해 둘 설정

### ① 성경 연결하기
예배송출에는 <b>성경 본문이 들어 있지 않습니다.</b> (번역본마다 저작권이 있기 때문입니다) 교회에서 쓸 수 있는 본문을 한 번 연결해 두세요. <b>⚙︎ 설정</b>에서 두 가지 방법 중 하나를 씁니다.

**방법 1 — 성경 폴더 연결** (번역본이 여러 개일 때 편함)
- 폴더 경로를 칸에 넣거나, Finder·탐색기에서 폴더를 칸으로 끌어다 놓고 <b>[추가]</b>.
- 폴더 모양:
  ```
  성경폴더/
  ├─ 한글 (개역개정)/
  │   ├─ 01-창세기(Genesis) - 개역개정.md
  │   └─ 43-요한복음(John) - 개역개정.md …
  └─ 영어 (ESV)/ …
  ```
  - 하위 폴더 하나가 번역본 하나입니다. 괄호 안 이름(개역개정, ESV)이 번역본 이름이 됩니다.
  - 파일 안에서 절은 `**3:16** 하나님이 세상을…` 처럼 한 줄에 한 절씩 적혀 있어야 합니다.
  - 원본 파일은 **읽기만** 하고 고치지 않습니다. `| 주석:` 뒤의 각주와 ①② 표시는 화면에 나오지 않습니다.

**방법 2 — 성경 텍스트 파일 가져오기**
- 번역본 이름을 적고 [파일 선택]으로 .txt 파일을 고릅니다.
- 한 줄에 한 절:
  - `창1:1 본문…` 형식, 또는
  - `창세기[탭]1[탭]1[탭]본문` 형식
- UTF-8, EUC-KR 모두 읽습니다.

연결한 뒤에는 **개역개정이 있으면 자동으로 기본 번역본**이 됩니다. 순서는 한글 → 영어 → 원어입니다.

### ② 자막 모양 정하기 — 🎨 자막 스타일
왼쪽은 **예배당 화면**, 오른쪽은 **방송 자막** 설정입니다. 바꾸는 즉시 아래 미리보기에 보이고, [적용]을 누르면 모든 슬라이드에 반영됩니다.

| 예배당 화면 | 방송 자막 |
|---|---|
| 글꼴, 글자 크기, 글자 색, 굵게 | 글꼴, 글자 크기, 글자 색, 굵게 |
| 그림자, 테두리 두께·색 | 자막 바 색, 바 불투명도 |
| 가로 정렬, 세로 위치(위·가운데·아래) | 위치(위·아래) |
| 배경색, **움직이는 배경** | 곡명·구절 표시 여부 |
| **화면 비율** (16:9 · 4:3) | (방송은 늘 16:9) |

**화면 비율** — 요즘 TV·프로젝터는 16:9 그대로 두세요. 네모에 가까운 옛 프로젝터(4:3)라 글자가 잘리거나 양옆이 비면 **4:3**으로 바꿉니다. 미리보기·슬라이드 그림도 4:3으로 보이고, 유튜브(OBS) 자막은 16:9 그대로입니다.

**글꼴** — 12가지 중에서 고릅니다. 프로그램 안에 들어 있어 **인터넷이 없어도** 그대로 나옵니다.

**다른 나라 말 자막 (베트남어·태국어·미얀마어)** — 가사나 말씀을 그 나라 말로 붙여넣으면 그대로 나옵니다. 고른 글꼴에 없는 글자는 함께 들어 있는 다국어 글꼴(Noto Sans)로 저절로 바뀝니다.
- 베트남어는 **본고딕·고운돋움·고운바탕**이나 **다국어 Noto Sans**를 고르면 성조 표시까지 고르게 나옵니다. 나눔고딕·주아 같은 글꼴은 성조 글자만 다른 모양으로 섞여 보일 수 있습니다.
- 태국어·미얀마어는 어느 글꼴을 골라도 그 나라 글꼴로 나옵니다. 글자 위아래 표시가 겹치지 않도록 줄 간격도 저절로 넓어집니다.
- 띄어쓰기가 없는 태국어·미얀마어도 낱말 단위로 줄이 바뀝니다.
본고딕 · 나눔고딕 · 고운돋움 · 나눔명조 · 고운바탕 · 송명 · 검은고딕(아주 굵게) · 도현 · 주아(둥근 글씨) · 나눔손글씨 펜 · 컴퓨터 기본 고딕

**글자 크기는 예배당과 유튜브를 따로** 정합니다. 예배 중에는 운영 화면 오른쪽 아래 <b>예배당 글자 － ＋</b>, <b>방송 글자 － ＋</b> 로 바로 키우고 줄일 수 있습니다.

> 팁: 예배당 화면은 글자를 크게, 방송 자막은 카메라 화면을 가리지 않게 작게 두세요.

**움직이는 배경** — 물이 흐르거나 별이 흘러가는 배경을 글자 뒤에 계속 반복해서 깝니다.
| 이름 | 모습 |
|---|---|
| 은하수 | 보랏빛 은하와 별이 천천히 흐름, 별이 반짝임 |
| 물결 | 푸른 물속에 물결이 겹겹이 흐르고 거품이 올라감 |
| 빛줄기 | 위에서 내려오는 따뜻한 빛줄기가 천천히 흔들림 |
| 빛망울 | 흐릿한 빛방울이 아래에서 위로 떠오름 |
| 오로라 | 초록·보라 빛이 하늘에서 일렁임 |
| 새벽 하늘 | 노을빛 하늘에 구름이 지나가고 해가 은은히 빛남 |
| 촛불빛 | 어두운 화면 아래에서 불씨가 피어오름 |
| 내 동영상 | 🖼 미디어에 올린 동영상(mp4·mov·webm)을 소리 없이 반복. [동영상 고르기]로 지정 |

- 동영상 파일 없이 화면에서 바로 그리므로 가볍고, **슬라이드를 넘겨도 끊기지 않고** 이어집니다.
- 그림 배경을 넣은 슬라이드, 악보·PPT·HTML 슬라이드에는 깔리지 않습니다.
- 예배 중에 끄려면 운영 화면의 <b>🌌 움직이는 배경</b> 버튼을 누르세요. 다시 누르면 켜집니다.
- 자료마다 다른 배경을 쓰려면 ✎ 편집 → <b>모양(테마)</b> 을 고르세요. ([5장 모양](#모양테마--자료마다-다른-분위기))

### ③ 교회 로고 (선택)
<b>⚙︎ 설정 → 로고 → [로고 선택]</b> 에서 로고 그림을 고릅니다. (png, 배경이 투명하면 더 좋습니다) 고르면 두 가지를 정할 수 있고, 미리보기로 바로 확인됩니다.

| | 하는 일 | 정할 것 |
|---|---|---|
| **로고 화면** | 예배 중 <b>✝ 로고</b> 버튼이나 **L** 키를 누르면 검은 화면에 로고만 띄움 | 위치(가운데·네 귀퉁이·위아래 가운데), 크기 |
| **항상 작게 띄우기** | 모든 슬라이드 한쪽 구석에 로고를 작게 늘 표시 (워터마크) | 켜기, 위치, 크기, 진하기, **유튜브에도** 표시할지 |

다 정했으면 <b>[로고 설정 저장]</b>. 로고를 없애려면 <b>[빼기]</b>.

**타이틀 로고** — 같은 곳의 <b>타이틀 로고 → [고르기]</b> 로 운영 화면 맨 위 '예배송출' 앞에 교회 로고를 작게 붙입니다. 고르지 않으면 ✝ 가 나옵니다.

### ④ 웹 편집기 PIN 확인
다른 컴퓨터에서 미리 준비할 때 쓰는 비밀번호입니다. 처음 실행할 때 **6자리로 무작위로** 정해집니다.
- <b>⚙︎ 설정</b>에서 확인하고, 6~12자리 숫자·영문으로 바꿀 수 있습니다.
- 바꾸면 이미 접속해 있던 다른 컴퓨터는 다시 로그인해야 합니다.

## 5. 자료 만들기

왼쪽 **예배 순서에 넣기**의 ＋ 버튼으로 만듭니다. 새 자료는 **예배 순서에서 지금 고른 자료 바로 다음**에 들어갑니다. (아무것도 안 골랐으면 맨 끝)

**무엇이 남고 무엇이 지워지나요**
- **찬양**(가사·악보)은 **찬양 자료실**에 계속 남아 다음 주에도 씁니다. 자료실 위 검색 칸에서 제목이나 가사로 찾으세요.
- **말씀·문구·광고·PPT·HTML**은 그 예배 순서에 딸린 자료입니다. 순서에서 <b>✕로 빼거나 예배 순서를 지우면 함께 지워져</b> 자료실에 쌓이지 않습니다.
- 지워지지 않게 하고 싶은 자료는 ✎ 편집에서 **종류**를 '찬양'으로 바꾸면 자료실에 남습니다.

### 찬양 — ＋ 찬양
1. **제목**을 적습니다.
2. **가사 붙여넣기** 칸에 가사를 통째로 붙여넣습니다.
3. 몇 줄씩 나눌지(1~6줄) 고르고 <b>[나누어 슬라이드 만들기]</b>.
   - **빈 줄**이 있는 곳에서는 무조건 나뉩니다. 절·후렴 사이에 빈 줄을 넣어 두면 깔끔합니다.
   - [뒤에 추가]를 누르면 기존 슬라이드는 두고 뒤에 이어 붙입니다.
4. 슬라이드마다 오른쪽 버튼으로 다듬습니다.
5. (선택) **콘티** 칸에 키(예: G)·빠르기(BPM)·흐름 메모(예: 후렴 2번)를 적어 두면 [6장 콘티](#콘티--찬양팀에-보낼-순서표)에 나옵니다.

**인터넷에서 가사 가져오기 — 프로그램 안에서 바로**
1. <b>가사 찾기</b> 칸에 곡 제목을 적고 <b>🔎 가사 찾아 넣기</b>(또는 Enter)를 누릅니다. 가수 이름을 함께 쓰면 더 잘 찾습니다.
2. 인터넷에서 찾은 가사가 목록으로 나옵니다. 곡 제목·가수·출처와 첫 두 줄이 보입니다.
3. 맞는 곡을 누르면 아래 가사 칸에 정리된 가사가 들어갑니다. (기타 코드·[후렴] 표시·작사/작곡 줄은 지우고 절 사이는 빈 줄로)
4. 확인한 뒤 <b>[나누어 슬라이드 만들기]</b>.

- 먼저 공개 가사 모음(LRCLIB)에서 찾고, 없으면 음악 사이트(벅스)에서 찾습니다. 버튼을 누를 때만 찾아옵니다.
- 못 찾으면 제목을 줄이거나 가수 이름을 넣어 보세요. 그래도 없으면 <b>구글</b>·<b>네이버</b>로 찾아 가사를 복사한 뒤 <b>📋 복사한 가사 붙여넣고 정리</b>를 누르면 됩니다.

> 가사는 저작권이 있으니 교회의 이용 허락 범위 안에서 쓰세요. (12장)

| 버튼 | 하는 일 |
|---|---|
| ↑ ↓ | 순서 바꾸기 |
| ✂ | 글자 칸에서 **커서가 있는 곳**을 기준으로 둘로 나누기 |
| ⇣ | 다음 슬라이드와 합치기 |
| 🖼 | 이 슬라이드 배경(사진·영상) 고르기 |
| 🗑 | 슬라이드 지우기 |

5. <b>[저장]</b>.

<b>곡 구성 (1절·후렴·브리지 순서)</b>
1. 슬라이드마다 아래 **이름** 칸에 `1절`, `후렴`, `브리지`처럼 적습니다. (목록에서 골라도 됨) 이름 붙은 슬라이드부터 다음 이름 전까지가 한 묶음입니다.
   - 가사를 붙여넣을 때 묶음 첫 줄에 `#1절`, `#후렴` 처럼 쓰면 이름이 저절로 붙습니다. 인터넷에서 복사한 가사의 `[Verse 1]`, `[Chorus]`, `후렴` 표시도 📋 정리 단추가 `#1절`, `#후렴`으로 바꿔 줍니다.
2. <b>곡 구성 (부를 순서)</b> 칸에 `1절 후렴 2절 후렴 브리지 후렴`처럼 적거나, 아래 이름 단추를 차례로 누릅니다.
3. 저장하면 슬라이드가 그 순서대로 펼쳐집니다. 후렴을 몇 번 부르든 **복사할 필요가 없고**, 후렴을 한 번 고치면 모두 바뀝니다. 슬라이드 오른쪽 위에 색깔 이름표(1절 파랑·후렴 주황·브리지 보라)가 붙습니다.
4. 칸을 비우면 원래 슬라이드 순서대로 나옵니다.

**전체 글로 고치기** — <b>📝 모든 슬라이드를 한 글로 보고 고치기</b>를 누르면 곡 전체가 한 글로 보입니다. 빈 줄이 슬라이드 나눔, `#후렴`이 이름입니다. 고친 뒤 <b>[슬라이드로 다시 나누기]</b>. 배경 그림은 같은 자리 슬라이드 것이 그대로 남습니다.

**곡 파일 가져오기** — 찬양 자료실 오른쪽 위 <b>가져오기</b>를 누르고 파일을 고르면 곡이 한꺼번에 자료실에 들어갑니다.
- **세라핌·동역 콘티에서 받은 곡 파일(.json)**: 가사가 들어 있는 곡만 들어갑니다.
- **가사 글 파일(.txt)**: 파일 하나가 한 곡이고, 파일 이름이 곡 제목이 됩니다.
- 2줄씩 나눠 슬라이드를 만듭니다. 자료실에 같은 제목이 있으면 건너뜁니다.

### 성경 — ＋ 성경
1. 구절을 입력하고 Enter. 이렇게 써도 다 알아듣습니다.
   - `요 3:16` · `요한복음 3장 16절` · `시 23:1-6` · `롬 8장` (장 전체)
   - `요한1서 1:9` · `John 3:16` · `1 John 1:9`
2. **번역본**을 고릅니다.
3. **함께 보일 번역본**을 고르면 한 슬라이드에 두 번역이 같이 나옵니다. (예: 개역개정 + ESV)
4. **슬라이드당 절 수**(1~3절)를 고르고 <b>[슬라이드 만들기]</b>.
   - 만든 말씀은 <b>오늘 예배 순서에 자동으로 들어갑니다.</b>
   - 화면 아래에 "요한복음 3:16 (개역개정)"처럼 구절이 표시됩니다.

### 문구·성찬 — ＋ 문구·성찬
"지금은 기도로 예배를 준비하는 시간입니다" 같은 자주 쓰는 문구를 눌러서 바로 넣습니다. 카드마다 실제 화면 모양이 미리 보입니다.

| 분류 | 문구 예 |
|---|---|
| 예배 준비 | 지금은 기도로 예배를 준비하는 시간입니다 · 휴대전화는 무음으로… · 잠시 후 예배가 시작됩니다 |
| 예배 순서 | 예배의 부름 · 경배와 찬양 · 신앙고백 · 대표 기도 · 성경 봉독 · 말씀 선포 · 봉헌 · 축도 … |
| 기도 | 다 함께 기도합니다 · 통성으로 기도합니다 · 중보 기도 시간입니다 … |
| 교제·광고 | 새가족을 환영합니다 · 생일·결혼기념일을 축하합니다 … |
| 마침 | 예배를 마칩니다 · 파송의 찬양 · 평안히 돌아가십시오 |
| 내 문구 | 아래 **직접 쓰기** 칸에 쓰고 <b>[내 문구로 저장]</b> 한 문구 |

- 위 **모양** 칸에서 화면 모양을 바꿔 넣을 수 있습니다. (기본은 분류에 맞게 자동)
- 넣은 뒤 ✎ 편집에서 "(기도하실 분)" 같은 자리를 실제 이름으로 고치세요.

**성찬 예식** — 맨 위 **성찬** 카드를 누르면 한 번에 들어갑니다. 촛불빛 배경의 따뜻한 화면입니다.
1. 성찬 예식 → 2. 성찬 제정의 말씀(고린도전서 11:23-26, 한 절씩) → 3. 감사 기도 → 4. 떡을 나눕니다 → 5. 잔을 나눕니다 → 6. 함께 기도합니다 → 7. 성찬 후 감사 찬양
- 제정의 말씀은 연결해 둔 성경(기본 번역본)에서 불러옵니다. 성경을 연결하지 않았으면 "＋ 성경으로 본문을 넣으세요" 안내 슬라이드가 대신 들어갑니다.

### 광고 — ＋ 광고
'광고 · 제목 강조' 모양으로 열립니다. 첫 줄은 노란 큰 제목, 다음 줄부터는 내용으로 나옵니다. 사진 배경은 🖼로 넣으세요.
교회 안에서만 알릴 내용이면 <b>유튜브 방송(OBS) → "보내지 않기"</b>로 두세요. 예배당 TV에만 나갑니다.

### HTML — ＋ HTML
웹 페이지(HTML)를 화면에 그대로 띄웁니다. ＋ HTML을 누르면 두 가지 중에서 고릅니다.

<b>📂 HTML 파일 가져오기 (여러 장짜리 발표 자료)</b>
- AI(ChatGPT·Claude 등)나 다른 프로그램으로 만든 **발표 자료 .html 파일**을 고릅니다. 여러 개를 한 번에 골라도 됩니다.
- 파일 안에 장이 여러 개면 **장마다 슬라이드**가 됩니다. 장 안의 글은 프롬프터(설교자 화면)에 보이고, ✎ 편집에서 고칠 수 있습니다.
- 파일 속 넘김 버튼·진행 막대는 숨기고, 넘기기는 예배송출에서만 합니다. 같은 파일 안에서 장을 넘길 때는 다시 불러오지 않아 깜빡이지 않습니다.
- HTML 파일 자료는 **예배당 화면·프롬프터에만** 나가고 유튜브(OBS)에는 나가지 않습니다. 파일 속 프로그램이 OBS를 건드리지 못하게 하기 위해서입니다.

<b>✏️ 직접 만들기</b> — 카운트다운 시계처럼 움직이는 화면을 만들 때 씁니다.
- <b>[HTML 파일 열기]</b> 로 .html 파일을 넣거나, 칸에 코드를 붙여넣습니다.
- 예시 두 가지가 들어 있습니다: **예배 시작 카운트다운**(5분부터 거꾸로, 코드의 `5 * 60` 을 바꾸면 시간 변경), **오늘의 말씀 카드**.
- 안전을 위해 HTML은 따로 떼어 낸 상자 안에서 돌아가므로 예배송출의 자료나 설정을 건드릴 수 없습니다.
- 유튜브(OBS)로 보낼 때는 HTML이 **멈춘 화면**으로 나갑니다. (카운트다운이 움직이지 않음) OBS의 방송·장면 제어 기능을 HTML이 건드리지 못하게 하기 위해서입니다. 움직이는 HTML은 예배당 TV에서만 움직입니다.
- 슬라이드 미리보기(작은 그림)에서는 움직이지 않고, 실제 화면에 띄울 때 움직입니다.
- 인터넷 주소의 그림·글꼴을 쓰는 HTML은 인터넷이 없으면 그 부분이 안 나옵니다.

### 모양(테마) — 자료마다 다른 분위기
✎ 편집 → <b>모양(테마)</b> 에서 고릅니다. 고르면 그 자료만 글꼴·색·배경이 바뀌고, 나머지는 🎨 자막 스타일을 따릅니다.

| 모양 | 어울리는 자료 |
|---|---|
| 찬양 · 은하수 / 물결 / 오로라 / 빛줄기 | 찬양 (움직이는 배경) |
| 말씀 · 명조 / 새벽 하늘 | 성경 말씀 (명조 글꼴, 구절 표시 금색) — ＋ 성경으로 만들면 '말씀 · 명조'가 기본 |
| 광고 · 제목 강조 / 밝은 화면 | 광고 (첫 줄이 제목) |
| 기도 · 빛망울 | 예배 준비·기도 |
| 순서 제목 | 예배의 부름·봉헌처럼 순서 이름만 크게 |
| 성찬 · 촛불빛 | 성찬 예식 |

### PPT — ＋ PPT
1. 쓰던 <b>.pptx</b> 파일을 고르면 슬라이드마다 **글자·표·그림이 원래 자리대로** 들어옵니다.
2. ✎ 편집에서
   - 글자 칸을 고쳐 쓰고,
   - 그림은 [그림 바꾸기]·[그림 삭제],
   - 표는 칸을 `|` 로, 줄을 줄바꿈으로 구분해 고칩니다.
3. 애니메이션과 화면 전환 효과는 가져오지 않습니다. 제목·본문 칸 위치가 원본과 조금 다를 수 있으니 한 번 훑어보세요.
4. 오래된 .ppt 파일은 파워포인트·키노트에서 <b>.pptx로 다시 저장</b>한 뒤 가져오세요.

### PDF·악보 — ＋ PDF·악보
1. **PDF** 또는 **악보 사진**(jpg·png, 여러 장 한 번에)을 고릅니다.
2. 선택 사항
   - **한 페이지 나누기**: 악보는 <b>"위·아래 2칸"</b>을 권합니다. 세로로 긴 A4 악보를 TV(가로 화면)에서 크게 볼 수 있습니다. 나눈 칸 사이는 조금 겹치게 잘라 악보 줄이 끊기지 않습니다. 주보·문서는 "나누지 않음".
   - **흰 여백 잘라내기**: 켜 두면 종이 여백을 잘라 더 크게 보입니다.
   - **배경색**: 악보는 흰색, 어두운 자료는 검정.
3. [가져오기]. PDF는 페이지마다, 사진은 장마다 슬라이드가 됩니다.

> 악보·PDF 슬라이드는 유튜브(OBS)에도 **화면 그대로** 나갑니다. 예배당에만 보내려면 ✎ 편집 → 유튜브 방송(OBS) → **보내지 않기**. ([8장](#8-유튜브-생중계에-자막-얹기-obs))

### 배경 사진·영상 — 🖼 미디어
1. <b>🖼 미디어 → ＋ 사진·영상 올리기</b>로 파일을 올립니다. (jpg·png·gif·webp·mp4·mov·webm 등)
2. 자료 편집 창에서 🖼(한 장) 또는 **모든 슬라이드 배경 → 배경 선택**(전체)으로 지정합니다.
3. 영상 배경은 **소리 없이 반복 재생**됩니다.
4. 광고 영상처럼 **소리를 들려줄 영상**은 그 슬라이드 아래 <b>🔊 소리 켜고 한 번 재생 (예배당 화면)</b> 을 체크하세요. 예배당 화면에서만 소리가 나고 한 번 재생 후 멈춥니다. (운영 화면 미리보기·유튜브 화면은 소리 없음)
   - 브라우저는 사람이 한 번도 누르지 않은 창의 소리를 막습니다. 예배 전에 **TV 창을 한 번 클릭하거나 F 키**로 전체화면을 해 두면 소리가 납니다. 막히면 운영 화면에 안내가 뜹니다.

> 음악 파일도 올릴 수는 있지만, 예배 중 재생하는 기능은 아직 없습니다.

## 6. 예배 순서 만들기

왼쪽 위 **예배 순서**에서 오늘 예배에 쓸 자료를 차례대로 모아 둡니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 새 예배 만들기 | 맨 위 <b>＋</b> → **순서 템플릿**·이름·날짜 → [만들기] |
| 찬양을 순서에 넣기 | 순서에서 넣을 자리 앞의 항목을 고른 뒤, 찬양 자료실의 곡에 마우스를 올리고 <b>＋</b> |
| 순서 바꾸기·빼기 | 순서 항목에 마우스를 올리고 <b>↑ ↓ ✕</b> (찬양은 자료실에 남고, 말씀·문구·광고는 지워짐) |
| 이름·날짜 바꾸기 / 지우기 | <b>✎</b> / <b>🗑</b> |
| 찬양팀에 순서표 보내기 | <b>📋</b> 콘티 (아래) |
| 다른 예배로 바꾸기 | 맨 위 목록에서 선택 |

**순서 템플릿** — 고르면 순서 제목 화면들이 미리 들어갑니다.
| 템플릿 | 들어가는 순서 |
|---|---|
| 주일 예배 | 예배 준비 → 예배의 부름 → 경배와 찬양 → 신앙고백 → 대표 기도 → 성경 봉독 → 말씀 선포 → 응답의 찬양 → 봉헌 → 교회 소식 → 축도 → 마침 |
| 성찬 주일 | 주일 예배 순서 + 말씀 뒤에 **성찬 예식** |
| 주일 오후 예배 | 예배 준비 → 찬양 → 기도 → 성경 봉독 → 말씀 → 봉헌 → 교회 소식 → 주기도문 |
| 찬양 예배 | 예배 준비 → 찬양으로 여는 예배 → 경배와 찬양 → 기도 → 말씀 → 결단의 찬양 → 축도 |
| 수요 예배 | 예배 준비 → 찬양 → 기도 → 성경 봉독 → 말씀 → 봉헌 → 주기도문 |
| 금요 기도회 | 예배 준비 → 경배와 찬양 → 말씀 → 통성 기도 → 중보 기도 → 마침 기도 |
| 새벽 기도회 | 새벽 기도회 → 찬송 → 말씀 → 개인 기도 |
| 빈 순서 | 아무것도 없이 시작 |

### 콘티 — 찬양팀에 보낼 순서표
예배 순서 맨 위 <b>📋</b>를 누르면 오늘 순서가 표로 나옵니다.
- 찬양마다 **키·BPM·흐름 메모**를 적습니다. 곡에 저장되어 다음에 그 곡을 쓸 때도 그대로 나옵니다.
- <b>전체 키 ♭ / ♯</b>: 모든 곡의 키를 반음씩 내리거나 올립니다. (G → A♭, F#m → Gm)
- **인도자 메모**: 순서 전체에 붙는 말 (예: 3번 곡 끝나고 바로 기도로)
- <b>💬 카톡용 복사</b>: 아래처럼 복사되니 카톡 방에 붙여넣으세요.
```
[2026-11-16 주일 예배] 콘티
1. 예배의 부름
2. 주님 다시 오실 때까지 (G, 72bpm)
   └ 후렴 2번, 마지막 조용히
3. 말씀: 요한복음 3:16
```
- <b>🖨 인쇄</b>: 종이 한 장 순서표로 인쇄합니다.
- 가사는 콘티에 들어가지 않습니다(저작권).

만든 뒤에는 이렇게 채웁니다: <b>"경배와 찬양"을 고르고</b> → 찬양 자료실에서 곡 <b>＋</b> (그 다음 자리에 들어감) → <b>"성경 봉독"을 고르고</b> → ＋ 성경 … 필요 없는 순서는 ✕로 빼세요.

## 7. 주일 예배 진행하기

### ① TV·프로젝터 연결
1. 노트북을 HDMI로 TV에 연결합니다.
2. 화면을 <b>"확장"</b>으로 둡니다. (<b>"미러링(복제)"이 아닙니다</b>)
   - 맥: 시스템 설정 → 디스플레이 → TV를 "확장 디스플레이"로
   - 윈도우: **윈도우 키 + P** → **확장**
3. 운영 화면에서 <b>📺 예배당 화면 열기</b>.
   - 모니터가 둘 이상이면 **어느 모니터에 띄울지 고르는 창**이 나옵니다. 고르면 그 모니터에 꽉 차게 열리고, 다음에는 지난번 선택이 표시됩니다. (처음 한 번 크롬·엣지가 "창 관리" 권한을 물으면 <b>[허용]</b>)
4. 열린 창이 TV에 있지 않으면 **TV 쪽으로 끌어다 놓고**, **F 키** (전체화면). 더블클릭해도 전체화면이 됩니다.
   - 마우스 커서는 이 화면에서 보이지 않습니다.
   - 다시 F 키를 누르면 전체화면이 풀립니다.
5. 옛 프로젝터(4:3)라 양옆이 비거나 글자가 잘리면 <b>🎨 자막 스타일 → 화면 비율 → 4:3</b>.

### ② 자막 넘기기
- **슬라이드를 클릭**하면 바로 TV와 유튜브에 나갑니다.
- **오타가 보이면** 슬라이드를 **마우스 오른쪽 클릭** → 빠른 수정 창에서 고치고 저장 (⌘/Ctrl + Enter). 띄워 둔 화면도 바로 바뀝니다.
- <b>⌘/Ctrl + F</b> 를 누르면 찬양 검색 칸으로 바로 갑니다.
- 오른쪽 미리보기로 지금 나가는 화면을, 아래 **다음 슬라이드** 칸으로 다음 내용을 확인하세요.

### ③ 단축키 (운영 화면에서)
| 키 | 하는 일 |
|---|---|
| <b>→</b>  **Space**  <b>↓</b>  **PageDown** | 다음 슬라이드 |
| <b>←</b>  <b>↑</b>  **PageUp** | 이전 슬라이드 |

<b>🎤 프롬프터 열기</b> → 강대상 모니터 등으로 옮기고 F 키. 지금 나가는 글자를 크게, 다음 슬라이드, 현재 시각, 송출 상태(송출 중·검은 화면·글자 지움)를 보여 줍니다.
> 프롬프터에 예배당 화면과 **똑같은 그림**을 띄우고 싶으면, 프롬프터 대신 <b>📺 예배당 화면 열기</b>를 한 번 더 눌러 그 창을 강대상 모니터로 옮기면 됩니다.

### ⑤ 미디어 배경 — 영상·사진을 배경으로 계속
가운데 아래 <b>🎞 미디어 배경</b> 칸에서 사진·영상을 **한 번 누르면** 예배당 화면 배경으로 계속 나옵니다. 찬양 시간 내내 같은 영상을 깔아 둘 때 좋습니다.
- 처음 실행하면 <b>기본 배경 영상 5개</b>(황금빛·푸른 물결·오로라·새벽 하늘·빛 입자)가 들어 있습니다. 직접 만든 영상이라 저작권 걱정 없이 쓰셔도 됩니다. 필요 없으면 지우세요. 다시 생기지 않습니다.
- 띄운 슬라이드가 없어도 배경은 보입니다. 예배 시작 전에 깔아 두기 좋습니다.
- 영상은 **소리 없이 반복**되고, 슬라이드를 넘겨도 <b>처음부터 다시 시작하지 않습니다.</b> 가사는 그 위에 얹혀 나옵니다.
- 악보·사진처럼 자기 그림이 있는 슬라이드는 그 그림이 먼저 보입니다.
- 지금 나가는 파일에는 빨간 테두리와 **LIVE**, 위쪽에 "● 배경: 파일 이름"이 보입니다. 영상은 마우스를 올리면 미리 재생되고 길이가 보입니다.
- <b>＋ 올리기</b>: 여러 파일을 한 번에. **전체·영상·사진**으로 골라 보기, 막대로 미리보기 크기 조절, <b>▾</b> 로 칸 접기.
- **맞춤**: 자동(영상은 꽉 채우기, 사진은 잘리지 않게) · 꽉 채우기 · 전체 보이기 · **작게**(가운데 작게, 정사각형 로고용). **파일마다 기억**합니다.
- <b>🎥 방송에도</b>: 켜면 같은 배경이 유튜브(OBS)에도 나가고 그 위에 자막 바가 얹힙니다. 카메라를 덮으므로 기본은 꺼짐입니다.
- <b>⏹ 배경 끄기</b> 또는 <b>모두 끄기(Esc)</b> 로 끕니다.
- 미리보기에 마우스를 올리면 <b>🗑</b> 로 파일을 지울 수 있습니다. 지우기 전에 지금 배경인지, 로고로 쓰는지, 몇 개 자료에서 쓰는지 알려 줍니다.
- 미디어 배경이 켜져 있으면 🌌 움직이는 배경은 잠시 쉽니다.

## 8. 유튜브 생중계에 자막 얹기 (OBS)

### 8-1. 방송은 이렇게 나갑니다
<b>예배 실황(카메라 영상)은 OBS가 유튜브로 내보냅니다.</b> 예배송출은 영상을 직접 방송하지 않고, OBS에 **투명한 자막 화면만** 넘겨줍니다.

```
카메라 ──────────────▶ OBS ──▶ 유튜브 생중계
                        ▲      (카메라 영상 + 자막)
예배송출 ─ 투명 자막 ───┘
   │
   └──── HDMI ──▶ 예배당 TV·프로젝터 (가사·말씀·악보 크게)
```

| 프로그램 | 하는 일 |
|---|---|
| **OBS** (무료, obsproject.com) | 카메라 영상과 소리를 받아서, 그 위에 예배송출 자막을 얹고, 유튜브로 내보냄. 방송 시작·종료도 OBS에서 |
| **예배송출** | 자막 만들기·넘기기, 예배당 TV 화면, OBS로 보낼 투명 자막 화면 |

- OBS는 **운영 노트북에서 함께** 돌려도 되고, **방송용 컴퓨터를 따로** 두어도 됩니다. 노트북 성능이 넉넉하지 않으면 따로 두는 편이 안정적입니다.
- "캡처 장비가 필요 없다"는 말은 **자막을 OBS로 보낼 때** 장비가 필요 없다는 뜻입니다. 카메라를 컴퓨터에 연결할 때는 카메라 종류에 따라 장치가 필요할 수 있습니다. (아래 8-2)

**자막은 양쪽에 함께 나갑니다**
슬라이드를 한 번 클릭하면 **같은 내용이 두 곳에 동시에** 나갑니다. 모양만 다릅니다.

| | 예배당 TV (HDMI) | 유튜브 (OBS) |
|---|---|---|
| 글자 (가사·말씀·문구) | 화면 가득 큰 글자, 배경 사진·영상·움직이는 배경 | 카메라 화면 아래쪽의 작은 자막 바 |
| 그림·악보·PDF·PPT 그림 | 나감 | 기본은 **화면 가득**. **화면 일부**(구석에 작게, 카메라가 보임)나 **보내지 않기**로 바꿀 수 있음 (아래) |
| HTML 파일 자료 | 나감 | 나가지 않음 |
| 미디어 배경 | 나감 | <b>🎥 방송에도</b>를 켰을 때만 |
| 검은 화면(B)·글자 지우기(C)·모두 끄기(Esc) | 적용 | 함께 적용 |
| 🎥 방송 자막 끄기(O) | 그대로 나감 | 꺼짐 |
| "방송에 내보내지 않기"로 정한 자료 | 나감 | 나가지 않음 |

**유튜브에만 자막을 끄고 싶을 때** (기도 제목, 교회 내부 광고 등)
- **잠깐 끄기**: 운영 화면 오른쪽의 <b>🎥 방송 자막 끄기</b> 버튼 또는 **O** 키. 다시 누르면 켜집니다. 꺼져 있는 동안 "방송 자막 (OBS)" 미리보기 옆에 빨간 글씨로 **꺼짐**이 표시되고, 프롬프터에도 "방송 자막 꺼짐"이 나옵니다. 끄기는 다시 켤 때까지 유지되니, 다음 순서 전에 꼭 다시 켜세요.
- **이 자료는 늘 끄기**: 자료 편집 창의 <b>유튜브 방송(OBS) → "보내지 않기"</b>를 고르고 저장합니다. 그 자료를 띄울 때만 자동으로 유튜브 자막이 꺼지고, 다른 자료로 넘어가면 다시 나갑니다. 목록에 **TV만** 표시가 붙습니다.

**방송 바로 조절** — 운영 화면 오른쪽 <b>🎥 방송 자막</b> 카드 아래 <b>▸ 방송 바로 조절</b>을 열면, 자막 스타일 창을 열지 않고 바로 바꿀 수 있습니다. 바꾸는 즉시 방송에 적용됩니다.
| 항목 | 고를 수 있는 것 |
|---|---|
| 그림 보내기 | **화면 가득** · <b>화면 일부 (카메라 보이게)</b> · <b>보내지 않기 (자막만)</b> |
| 일부 — 크기·위치 | 15~70% · 오른쪽/왼쪽 × 위/중간/아래 (6곳). 화면 일부일 때만 보임 |
| 자막 위치 · 바 진하기 · 곡명·구절 | 자막 바 모양 |
| 미디어 배경 | 방송에도 내보내기 |

'화면 일부'는 OBS 설정 없이 그림이 구석에 작게 얹히고 나머지는 카메라가 보입니다. 설교자를 크게 보여 주면서 악보·광고를 곁들일 때 좋습니다. (8-5의 사람 화면은 반대로 그림이 크고 사람이 작게)

> 팁: 카메라에 예배당 TV 화면이 크게 잡히면, 유튜브에서는 자막이 두 번(TV 속 자막 + 아래 자막 바) 보입니다. 카메라를 강대상 중심으로 잡거나, 자막 스타일에서 방송 자막 위치를 위쪽으로 바꿔 보세요.

### 8-2. 카메라 연결하기
| 카메라 | 연결 방법 |
|---|---|
| **USB 웹캠** | USB에 꽂으면 바로 OBS에서 보입니다. 추가 장치가 필요 없습니다. |
| **캠코더·미러리스·DSLR** (HDMI 출력) | 카메라 HDMI → **캡처 장치**(USB 캡처 동글·캡처 카드) → 컴퓨터 USB. 카메라에 "USB 웹캠 모드"가 있으면 캡처 장치 없이 USB로 바로 연결되기도 하니 먼저 확인해 보세요. |
| **아이폰** (맥) | 맥의 "연속성 카메라"로 아이폰을 웹캠처럼 쓸 수 있습니다. 거치대에 고정해 두세요. |

OBS에서 카메라 넣기: **소스 ＋ → 비디오 캡처 장치** → 카메라(또는 캡처 장치)를 고릅니다.

**소리**: 강단 마이크·찬양 소리는 교회 **음향 믹서의 출력**을 컴퓨터 오디오 입력(또는 USB 오디오 인터페이스)으로 넣으세요. OBS의 오디오 믹서에서 소리 크기가 움직이는지 확인합니다. 카메라 내장 마이크만 쓰면 예배당 울림 때문에 소리가 멀게 들립니다.

### 8-3. 유튜브 연결하기 (처음 한 번)
1. 유튜브 채널에서 **실시간 스트리밍을 사용 설정**합니다. (YouTube Studio → 만들기 → 라이브 스트리밍 시작) 처음 신청하면 사용할 수 있게 되기까지 **최대 24시간**이 걸릴 수 있으니 미리 해 두세요.
2. OBS **설정 → 방송** → 서비스를 **YouTube** 로 고르고 <b>[계정 연결]</b>, 또는 YouTube Studio에 나오는 **스트림 키**를 붙여넣습니다.

### 8-4. 예배송출 자막 얹기
1. 운영 화면 <b>🎥 OBS 자막 주소</b>를 눌러 주소를 <b>[복사]</b> 합니다. (예: `http://192.168.0.10:5300/overlay`)
   - OBS를 **운영 노트북에서 함께** 돌린다면: `http://localhost:5300/overlay`
2. OBS에서 **소스 ＋ → 브라우저**를 추가합니다.
3. **URL**에 주소를 붙여넣고, **너비 1920, 높이 1080**으로 둡니다.
4. 소스 목록에서 브라우저 소스를 **카메라 소스보다 위로** 올립니다. (위에 있는 소스가 화면 앞에 보입니다)
5. 운영 화면에서 슬라이드를 클릭해 OBS 화면에 자막이 나오는지 확인합니다.

한 번 설정해 두면 OBS가 기억하므로, 다음 주부터는 다시 할 필요가 없습니다.

**자료마다 유튜브로 보내는 방식** — ✎ 편집 → 유튜브 방송(OBS)
| 선택 | 유튜브에 나가는 것 |
|---|---|
| 자동 (기본) | 글자는 자막 바로, 그림·악보·HTML은 화면 그대로 |
| 예배당 화면 그대로 보내기 | 배경·글꼴까지 예배당 TV와 똑같이 (설교 요약 PPT 등) |
| 보내지 않기 | 아무것도 안 나가고 카메라만 보임 (기도 제목 등) |

### 8-5. 그림을 보낼 때 오른쪽 아래에 사람 화면
광고 사진·악보 같은 그림을 유튜브에 띄우면 카메라가 가려집니다. 이때 **설교자·인도자 모습을 오른쪽 아래에 작게** 띄울 수 있습니다. OBS가 장면을 바꿔서 하는 일이라 처음 한 번 설정이 필요합니다.

1. 지금 쓰는 장면(예: **예배**)은 그대로 둡니다. (카메라 + 그 위에 예배송출 자막 브라우저 소스)
2. OBS 장면 목록 아래 <b>＋</b>로 장면을 하나 더 만듭니다. (예: **예배-그림**)
3. 새 장면에서 소스 <b>＋ → 브라우저 → "기존 소스 추가"</b> 로 예배송출 자막 소스를 넣습니다.
4. 같은 장면에 소스 <b>＋ → 비디오 캡처 장치 → "기존 소스 추가"</b> 로 카메라를 넣고, **자막 소스보다 위**로 올린 뒤 오른쪽 아래에 작게 줄여 놓습니다. (모서리를 끌어 크기 조절)
5. 예배송출 자막 브라우저 소스를 더블클릭 → **페이지 권한**을 <b>"고급 접근 권한"</b>(장면 변경 가능 / 영어: Advanced access to OBS)으로 바꿉니다.
6. 운영 화면 <b>🎥 OBS 자막 주소</b> 창 아래 **사람 화면** 칸에서 '평소 장면'은 **예배**, '사람 화면 장면'은 **예배-그림**을 고르고 <b>[장면 저장]</b>. (OBS가 연결되어 있으면 장면 이름이 목록으로 나오고, 상태에 "OBS 장면 전환 가능"이 보입니다)

이제 그림·악보·PPT 그림·HTML을 띄우면 OBS가 **예배-그림** 장면으로, 글자 자막으로 돌아오면 **예배** 장면으로 **알아서** 바뀝니다.
- 운영 화면 <b>👤 사람 화면</b> 버튼(**P** 키)으로 켜고 끕니다. 끄면 그림만 화면 가득 나갑니다. 켜져 있을 때 방송 미리보기 오른쪽 아래에 "👤 사람 화면" 자리가 점선으로 보입니다.
- '예배'·'예배-그림'이 아닌 다른 장면(예: 설교 전용 장면)에 있을 때는 장면을 바꾸지 않습니다.
- OBS 28 이상에서 됩니다.
- '그림 보내기'를 **화면 일부**로 해 두면 이 장면 전환은 하지 않습니다. (이미 카메라가 보이므로)

### 8-6. 주일 방송 순서
1. 카메라·음향 연결 → **OBS 켜기** → 카메라 화면과 소리 확인
2. **예배송출 켜기** → 슬라이드 하나를 띄워 OBS에 자막이 나오는지 확인 → **Esc**로 자막 끄기
3. 예배 시작 5~10분 전 OBS에서 <b>[방송 시작]</b>
4. 예배 중에는 예배송출에서 자막만 넘깁니다.
5. 예배가 끝나면 OBS에서 <b>[방송 중단]</b> → 예배송출 <b>⏻ 종료</b>

### 8-7. 예배당·다른 방 TV에 방송 화면(카메라 + 자막) 띄우기
유튜브로 나가는 화면을 **그대로** TV에 띄울 수 있습니다. 본당 뒤쪽 TV, 자모실, 식당, 로비처럼 강단이 잘 안 보이는 곳에 좋습니다. 이건 OBS가 하는 일입니다.

1. **OBS를 돌리는 컴퓨터**에 TV를 HDMI로 연결하고, 화면을 <b>"확장"</b>으로 둡니다. ([7장 ①](#7-주일-예배-진행하기))
2. OBS 가운데 방송 화면에서 **마우스 오른쪽 클릭 → 전체 화면 프로젝터 (프로그램) → TV 모니터**를 고릅니다.
3. 카메라 영상 + 예배송출 자막이 TV에 꽉 차게 나옵니다. 끌 때는 그 화면에서 **Esc**.

TV가 몇 대인지에 따라
| 연결 | 할 수 있는 것 |
|---|---|
| 노트북 1대 + TV 1대 | 예배송출 큰 자막 **또는** OBS 방송 화면, 둘 중 하나 |
| 노트북 1대 + TV 2대 | 본당 TV에는 예배송출 큰 자막, 다른 TV에는 OBS 방송 화면 (노트북에 화면 출력 단자가 2개 필요. 맥북 에어 등 일부는 외부 화면을 1대만 지원) |
| 운영 노트북 + 방송 컴퓨터 | 운영 노트북 TV에는 큰 자막, 방송 컴퓨터 TV에는 방송 화면 |

주의할 점
- 이 화면에는 유튜브와 **똑같은 것**이 나갑니다. 🎥 방송 자막 끄기(O)를 누르면 이 TV에서도 자막이 사라집니다.
- **카메라가 비추는 곳에 이 TV가 있으면** 화면 속에 화면이 계속 겹쳐 보이는 현상이 생깁니다. 본당에 둘 때는 카메라에 잡히지 않는 자리에 두세요.
- OBS 프로젝터는 **화면만** 보여 줍니다. 다른 방에서 설교 소리도 들으려면 음향 믹서에서 그 방 스피커로 소리를 보내세요.
- 유튜브 시청자가 보는 영상은 보통 수십 초 늦게 나가지만, 이 TV 화면은 늦지 않고 바로 나옵니다.

### 알아 둘 점
- 방송 컴퓨터는 맥이든 윈도우든 상관없습니다. 운영 노트북과 <b>같은 공유기(와이파이)</b>에만 연결되어 있으면 됩니다.
- 글자 슬라이드는 자막 바로 나가고, 배경 사진·움직이는 배경은 나가지 않습니다. 그림·악보는 화면 그대로 나갑니다.
- 자막 모양은 🎨 자막 스타일 → 오른쪽 "방송 자막"에서 바꿉니다.
- 공유기가 바뀌면 주소(숫자)도 바뀔 수 있습니다. 자막이 안 나오면 주소를 다시 복사해 넣으세요.

## 9. 주중에 미리 준비하기 (웹 편집기)

집이나 사무실 컴퓨터(윈도우도 됨) 브라우저에서 곡·말씀·문구·광고·PPT·HTML·예배 순서를 미리 준비합니다.

1. 운영 노트북에서 예배송출을 **켜 둡니다**.
2. 🎥 OBS 자막 주소 창에 적힌 **웹 편집기 주소**와 **PIN**을 확인합니다. (예: `http://192.168.0.10:5300/editor`)
3. 다른 컴퓨터 브라우저에 주소를 넣고 PIN을 입력합니다.
4. 운영 화면과 같은 방식으로 준비합니다. 저장하면 운영 노트북에도 **바로** 반영됩니다.

- 웹 편집기에서는 <b>송출 버튼이 없습니다.</b> 화면 송출은 운영 노트북에서만 할 수 있습니다.
- 같은 공유기(와이파이)에 연결된 컴퓨터에서만 접속됩니다.
- PIN을 **5번 틀리면 5분 동안** 잠깁니다.

### 휴대폰 리모컨
강대상이나 찬양팀 자리에서 **휴대폰으로 자막을 넘길** 수 있습니다.
1. 운영 컴퓨터 <b>⚙︎ 설정 → 📱 휴대폰 리모컨 → "휴대폰에서 자막 넘기기 허용"</b>을 켭니다. (처음에는 꺼져 있습니다)
2. 같은 와이파이의 휴대폰 브라우저에서 설정에 적힌 주소(예: `http://192.168.0.10:5300/remote`)를 열고 **PIN**을 넣습니다.
3. 큰 <b>◀ 이전 · 다음 ▶</b>, 검은화면·글자 지움·로고·방송 끄기·모두 끄기, 지금·다음 가사, 슬라이드 목록과 예배 순서가 나옵니다. 누르면 바로 TV·유튜브에 나갑니다.
- 리모컨을 끄면 휴대폰에서는 다시 넘길 수 없습니다. 예배가 끝나면 꺼 두는 것을 권합니다.

## 10. 백업·컴퓨터 옮기기·업데이트

### 자료가 저장되는 곳
| 컴퓨터 | 폴더 |
|---|---|
| 맥 | `~/Library/Application Support/WorshipCaster` (Finder → 이동 → 폴더로 이동에 붙여넣기) |
| 윈도우 | `%APPDATA%\WorshipCaster` (탐색기 주소창에 붙여넣기) |

이 폴더 안에 곡·예배 순서·스타일·설정(`db.json`), 올린 사진·영상(`media`), 가져온 성경 텍스트(`bible`)가 있습니다.

- **백업**: <b>⚙︎ 설정 → 💾 백업·복원 → [자료 전체 백업 받기]</b>. 찬양·예배 순서·모양·설정·사진·영상·HTML·가져온 성경 텍스트가 zip 파일 하나로 내려받아집니다. 한 달에 한 번쯤 USB나 클라우드에 두세요.
  - 가져온 성경 텍스트와 PIN이 들어 있으니 백업 파일은 남에게 나누지 마세요.
- **새 컴퓨터로 옮기기**: 새 컴퓨터에 예배송출을 설치하고 켠 뒤 <b>⚙︎ 설정 → 💾 백업·복원 → [백업 파일로 되살리기]</b>에서 zip 파일을 고릅니다. 지금 자료가 백업 내용으로 바뀝니다. (바뀌기 전 자료도 `db.before-restore-….json`으로 한 벌 남습니다)
  - 위 폴더를 통째로 복사해 바꿔 넣어도 됩니다. (프로그램을 끈 상태에서)
  - 성경 폴더를 연결했었다면 새 컴퓨터에서 경로가 달라질 수 있으니 ⚙︎ 설정에서 다시 연결하세요.
- **업데이트**: 새 버전이 나오면 운영 화면 맨 위에 <b>🔔 새 버전 v…</b> 단추가 생깁니다. 누르면 받는 곳이 열립니다. 새 버전을 받아 앱(또는 폴더)만 바꾸면 됩니다. 자료는 그대로 남습니다. (바꾸기 전에 ⚙︎ 설정 → 💾 백업을 받아 두면 더 안심입니다)
  - 알림은 GitHub에서 최신 버전 번호만 확인하고, 이쪽 정보는 보내지 않습니다. 6시간에 한 번 확인합니다. 끄려면 ⚙︎ 설정 맨 아래 <b>새 버전이 나오면 알려 주기</b>를 끄세요.

## 11. 이럴 땐 이렇게 (문제 해결)

**미얀마어 가사가 뒤섞여 보여요 / "옛 방식(자우기)" 안내가 떠요**
→ 그 글이 옛 미얀마 글자 방식(자우기, Zawgyi)으로 쓰여 있습니다. 예배송출은 요즘 표준(유니코드) 글자를 씁니다. 인터넷이나 휴대폰 앱의 "Zawgyi to Unicode" 변환기로 바꾼 뒤 다시 붙여넣으세요. 미얀마 교인께 "유니코드로 보내 주세요"라고 부탁하셔도 됩니다.

**처음 실행할 때 경고창이 떠요**
→ 무료 프로그램이라 나오는 안내입니다. [2. 설치하기](#2-설치하기)의 방법대로 처음 한 번만 허용하세요.

**TV에 노트북 화면이 똑같이 나와요 / 자막 창이 TV로 안 가요**
→ 화면이 "미러링"으로 되어 있습니다. "확장"으로 바꾸세요. ([7장 ①](#7-주일-예배-진행하기))

**TV에서 화면 위아래(양옆)에 검은 띠가 생겨요**
→ 화면을 16:9 비율로 맞추기 때문입니다. TV·프로젝터의 화면 비율 설정을 16:9로 두세요.

**OBS에 자막이 안 보여요**
1. 운영 화면에서 슬라이드를 하나 클릭했는지 (아무것도 안 띄우면 투명합니다)
2. 브라우저 소스가 카메라 소스 **위에** 있는지
3. 방송 컴퓨터와 운영 노트북이 같은 공유기에 있는지
4. 주소가 바뀌지 않았는지 (🎥 OBS 자막 주소에서 다시 복사)
5. 운영 노트북의 방화벽에서 예배송출(윈도우는 node)이 **허용**되어 있는지

**OBS에서 자막 화면 바탕이 검게 나와 카메라를 가려요 / OBS에서 글자가 아주 작게 나와요**
→ 0.5.0에서 고쳤습니다. 예배송출을 새 버전으로 바꾸고, OBS 브라우저 소스 속성에서 <b>[현재 페이지의 캐시 새로고침]</b>을 한 번 누르세요. 오래된 OBS(28 이하)의 내장 브라우저에서도 글자 크기가 맞게 나옵니다.

**슬라이드를 바꿨는데 예배당 화면이 검게만 나와요**
→ 0.5.0에서 고쳤습니다. (창이 가려져 있으면 새 화면이 투명한 채로 남던 문제) 같은 컴퓨터에서 ProPresenter 같은 다른 송출 프로그램이 켜져 있으면 그 프로그램의 전체화면이 TV를 덮을 수 있으니 끄세요.

**웹 편집기에 접속이 안 돼요**
→ 운영 노트북이 켜져 있고 예배송출이 실행 중인지, 같은 와이파이인지 확인하세요. 학교·회사처럼 기기끼리 접속을 막는 와이파이에서는 안 될 수 있습니다.

**성경을 못 찾는다고 나와요**
→ ⚙︎ 설정에서 성경을 연결했는지 확인하세요. 그 번역본에 해당 장이 있는지, 책 이름이 맞는지(`요`, `요한복음`, `John`) 확인하세요.

**글꼴이 설정과 다르게 보여요**
→ 글꼴은 프로그램에 들어 있어 인터넷 없이도 나옵니다. 처음 한 번 그 글꼴을 쓸 때 아주 잠깐 기본 글꼴로 보였다가 바뀔 수 있습니다. 예배 전에 한 번 띄워 보세요.

**움직이는 배경이 끊기거나 노트북이 뜨거워져요**
→ 오래된 노트북에서는 무거울 수 있습니다. 🌌 움직이는 배경 버튼으로 끄거나, 빛망울·촛불빛보다 가벼운 새벽 하늘·오로라를 써 보세요.

<b>그림을 띄워도 OBS 장면이 안 바뀌어요 (사람 화면)</b>
1. 👤 사람 화면 버튼이 켜져 있는지
2. 자막 브라우저 소스의 페이지 권한이 "고급 접근 권한"인지 (🎥 OBS 자막 주소 창의 상태 확인)
3. 저장한 장면 이름이 OBS 장면 이름과 똑같은지
4. 지금 OBS가 '평소 장면'이나 '사람 화면 장면' 중 하나에 있는지

**프로그램을 껐는데 다시 안 켜져요 / 이상하게 동작해요**
→ 컴퓨터를 한 번 다시 시작해 보세요. 그래도 안 되면 기록 파일을 함께 보내 주세요.
- 맥: `~/Library/Logs/WorshipCaster.log`
- 윈도우: 작업 표시줄의 WorshipCaster 창에 나온 글

## 12. 저작권 안내

- **성경**: 개역개정·새번역·현대인의성경과 ESV·NIV·NLT 등은 저작권이 있는 번역본입니다. 예배당 화면이나 유튜브로 내보내기 전에 교회가 사용 허가를 받았는지 확인하세요. 개역한글은 저작권이 만료되었습니다.
- **찬양 가사·악보**: 곡마다 저작권이 있습니다. 특히 유튜브 생중계·다시보기에 가사를 띄울 때는 교회가 필요한 이용 허락을 받았는지 확인하세요.
- **글꼴**: 프로그램에 들어 있는 글꼴(본고딕·나눔·고운·송명·검은고딕·도현·주아, 다국어 Noto Sans·Thai·Myanmar)은 모두 무료로 쓸 수 있는 공개 글꼴(SIL 오픈 폰트 라이선스)입니다.
- 예배송출 프로그램 자체는 무료입니다.
