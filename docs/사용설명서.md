## 1. 준비물

| 꼭 필요 | 있으면 좋음 |
|---|---|
| 노트북 1대 (맥 또는 윈도우 10·11) | 유튜브 방송용 카메라 + 무료 방송 프로그램 OBS (같은 노트북이어도, 다른 컴퓨터여도 됨) — HDMI 카메라는 캡처 장치 필요 ([8장](#8-유튜브-생중계에-자막-얹기-obs)) |
| TV·프로젝터와 연결할 HDMI 선 (맥은 USB-C→HDMI 젠더가 필요할 수 있음) | 같은 와이파이(공유기) — OBS를 다른 컴퓨터에서 쓰거나 웹 편집기를 쓸 때 |

- **인터넷이 없어도** 예배 진행은 됩니다.
- 이 노트북을 **운영 노트북**이라고 부르겠습니다. 자막을 넘기는 컴퓨터입니다.

## 2. 설치하기

다운로드: **https://github.com/raon-easypaster/worship-caster/releases**
따로 설치할 프로그램(Node.js 등)은 없습니다.

### 맥 (애플 칩 M1~ · 인텔 맥 모두)
1. **WorshipCaster-mac.zip** 을 받아 더블클릭해 압축을 풉니다.
2. **예배송출.app** 을 Finder 왼쪽의 **응용 프로그램** 폴더로 끌어다 놓습니다.
3. 예배송출을 더블클릭합니다.
4. **처음 한 번만** "확인할 수 없습니다"라는 창이 뜹니다.
   - [완료]를 누르고 → **시스템 설정 → 개인정보 보호 및 보안** → 맨 아래 "예배송출" 옆 **[그래도 열기]** → 다시 [열기].
   - 애플 유료 개발자 인증을 받지 않은 무료 프로그램이라 나오는 안내입니다.
5. "로컬 네트워크의 기기를 찾도록 허용" 또는 방화벽 질문이 나오면 **[허용]** 하세요.
6. 운영 화면이 열리면 설치 끝입니다.

### 윈도우 10·11 (64비트)
1. **WorshipCaster-windows.zip** 을 받아 오른쪽 클릭 → **모두 압축 풀기**.
2. 나온 `예배송출` 폴더를 문서 폴더 등 원하는 곳에 둡니다. (바탕화면에 바로가기를 만들어 두면 편합니다)
3. 폴더 안의 **예배송출 실행.cmd** 를 더블클릭합니다.
4. "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**.
5. 방화벽 질문이 나오면 **[액세스 허용]**.
6. 엣지 창으로 운영 화면이 열립니다.
   - 작업 표시줄의 **WorshipCaster** 창은 프로그램 본체입니다. **닫으면 프로그램이 꺼집니다.**

### 켜고 끄기
- **켜기**: 아이콘(맥) 또는 `예배송출 실행.cmd`(윈도우) 더블클릭. 이미 켜져 있으면 운영 화면 창만 다시 열립니다.
- **끄기**: 운영 화면 오른쪽 위 **⏻ 종료**.

## 3. 화면 둘러보기

### 운영 화면

```
┌──────────────────────────────────────────────────────────────────────┐
│ ✝ 예배송출   [📺 예배당 화면 열기] [🎤 프롬프터 열기] [🎥 OBS 자막 주소] │
│              [🎨 자막 스타일] [🖼 미디어] [⚙︎ 설정] [⏻ 종료]          │
├──────────────┬────────────────────────────────┬──────────────────────┤
│ 예배 순서     │  선택한 자료의 슬라이드          │ 예배당 화면 미리보기   │
│  ① 광고       │  ┌────┐ ┌────┐ ┌────┐           │ 방송 자막 미리보기     │
│  ② 찬양       │  │ 1  │ │ 2  │ │ 3  │  ← 클릭하면 │ [◀ 이전] [다음 ▶]     │
│  ③ 말씀       │  └────┘ └────┘ └────┘    바로 송출 │ [■ 검은화면] [◻ 글자] │
│ 자료실        │                                │ [✝ 로고] [모두 끄기]   │
│  ＋찬양 ＋성경 │                                │ 다음 슬라이드          │
│  ＋광고 ＋PPT  │                                │                      │
│  ＋PDF·악보   │                                │                      │
└──────────────┴────────────────────────────────┴──────────────────────┘
```

- **왼쪽**: 위는 오늘의 **예배 순서**, 아래는 지금까지 만든 모든 자료가 있는 **자료실**입니다.
- **가운데**: 고른 자료의 슬라이드들. **클릭하면 바로 화면에 나갑니다.** 지금 나가는 슬라이드는 빨간 테두리로 표시됩니다.
- **오른쪽**: 지금 TV와 유튜브에 나가는 모습 미리보기, 그리고 송출 버튼들.

### 함께 쓰는 화면 4가지
| 화면 | 쓰는 곳 | 여는 법 |
|---|---|---|
| **예배당 화면** | TV·프로젝터 (HDMI) | 📺 예배당 화면 열기 |
| **방송 자막** | 유튜브 방송(OBS). 배경이 투명해 카메라 화면 위에 자막만 얹힘 | 🎥 OBS 자막 주소 |
| **프롬프터** | 설교자·인도자용 모니터. 지금 화면 + 다음 화면 + 시계 | 🎤 프롬프터 열기 |
| **웹 편집기** | 다른 컴퓨터에서 미리 준비 (송출은 못 함) | 🎥 OBS 자막 주소 창에 주소가 있음 |

## 4. 처음 한 번 해 둘 설정

### ① 성경 연결하기
예배송출에는 **성경 본문이 들어 있지 않습니다.** (번역본마다 저작권이 있기 때문입니다) 교회에서 쓸 수 있는 본문을 한 번 연결해 두세요. **⚙︎ 설정**에서 두 가지 방법 중 하나를 씁니다.

**방법 1 — 성경 폴더 연결** (번역본이 여러 개일 때 편함)
- 폴더 경로를 칸에 넣거나, Finder·탐색기에서 폴더를 칸으로 끌어다 놓고 **[추가]**.
- 폴더 모양:
  ```
  성경폴더/
  ├─ 한글 (개역개정)/
  │   ├─ 01-창세기(Genesis) - 개역개정.md
  │   └─ 43-요한복음(John) - 개역개정.md …
  └─ 영어 (ESV)/ …
  ```
  - 하위 폴더 하나가 번역본 하나입니다. 괄호 안 이름(개역개정, ESV)이 번역본 이름이 됩니다.
  - 파일 안에서 절은 `**3:16** 하나님이 세상을…` 처럼 한 줄에 한 절씩 적혀 있어야 합니다.
  - 원본 파일은 **읽기만** 하고 고치지 않습니다. `| 주석:` 뒤의 각주와 ①② 표시는 화면에 나오지 않습니다.

**방법 2 — 성경 텍스트 파일 가져오기**
- 번역본 이름을 적고 [파일 선택]으로 .txt 파일을 고릅니다.
- 한 줄에 한 절:
  - `창1:1 본문…` 형식, 또는
  - `창세기[탭]1[탭]1[탭]본문` 형식
- UTF-8, EUC-KR 모두 읽습니다.

연결한 뒤에는 **개역개정이 있으면 자동으로 기본 번역본**이 됩니다. 순서는 한글 → 영어 → 원어입니다.

### ② 자막 모양 정하기 — 🎨 자막 스타일
왼쪽은 **예배당 화면**, 오른쪽은 **방송 자막** 설정입니다. 바꾸는 즉시 아래 미리보기에 보이고, [적용]을 누르면 모든 슬라이드에 반영됩니다.

| 예배당 화면 | 방송 자막 |
|---|---|
| 글꼴, 글자 크기, 글자 색, 굵게 | 글꼴, 글자 크기, 글자 색, 굵게 |
| 그림자, 테두리 두께·색 | 자막 바 색, 바 불투명도 |
| 가로 정렬, 세로 위치(위·가운데·아래) | 위치(위·아래) |
| 배경색 | 곡명·구절 표시 여부 |

> 팁: 예배당 화면은 글자를 크게, 방송 자막은 카메라 화면을 가리지 않게 작게 두세요.

### ③ 교회 로고 (선택)
**⚙︎ 설정 → 로고 선택**에서 로고 그림을 고르면, 예배 중 **L** 키로 검은 화면 위에 로고를 띄울 수 있습니다.

### ④ 웹 편집기 PIN 확인
다른 컴퓨터에서 미리 준비할 때 쓰는 비밀번호입니다. 처음 실행할 때 **6자리로 무작위로** 정해집니다.
- **⚙︎ 설정**에서 확인하고, 6~12자리 숫자·영문으로 바꿀 수 있습니다.
- 바꾸면 이미 접속해 있던 다른 컴퓨터는 다시 로그인해야 합니다.

## 5. 자료 만들기

자료는 **자료실**에 쌓이고, 한 번 만들면 다음 주에도 계속 쓸 수 있습니다. 자료실 위 검색 칸에서 제목이나 가사로 찾으세요.

### 찬양 — ＋ 찬양
1. **제목**을 적습니다.
2. **가사 붙여넣기** 칸에 가사를 통째로 붙여넣습니다.
3. 몇 줄씩 나눌지(1~6줄) 고르고 **[나누어 슬라이드 만들기]**.
   - **빈 줄**이 있는 곳에서는 무조건 나뉩니다. 절·후렴 사이에 빈 줄을 넣어 두면 깔끔합니다.
   - [뒤에 추가]를 누르면 기존 슬라이드는 두고 뒤에 이어 붙입니다.
4. 슬라이드마다 오른쪽 버튼으로 다듬습니다.

| 버튼 | 하는 일 |
|---|---|
| ↑ ↓ | 순서 바꾸기 |
| ✂ | 글자 칸에서 **커서가 있는 곳**을 기준으로 둘로 나누기 |
| ⇣ | 다음 슬라이드와 합치기 |
| 🖼 | 이 슬라이드 배경(사진·영상) 고르기 |
| 🗑 | 슬라이드 지우기 |

5. **[저장]**.

> 같은 후렴을 여러 번 부를 때는 예배 중에 그 슬라이드를 다시 클릭하면 됩니다. 복사해서 늘릴 필요가 없습니다.

### 성경 — ＋ 성경
1. 구절을 입력하고 Enter. 이렇게 써도 다 알아듣습니다.
   - `요 3:16` · `요한복음 3장 16절` · `시 23:1-6` · `롬 8장` (장 전체)
   - `요한1서 1:9` · `John 3:16` · `1 John 1:9`
2. **번역본**을 고릅니다.
3. **함께 보일 번역본**을 고르면 한 슬라이드에 두 번역이 같이 나옵니다. (예: 개역개정 + ESV)
4. **슬라이드당 절 수**(1~3절)를 고르고 **[슬라이드 만들기]**.
   - 만든 말씀은 **오늘 예배 순서에 자동으로 들어갑니다.**
   - 화면 아래에 "요한복음 3:16 (개역개정)"처럼 구절이 표시됩니다.

### 광고 — ＋ 광고
찬양과 같은 편집 창입니다. 광고 문구를 한 슬라이드씩 적고, 🖼로 사진 배경을 넣어 보세요.
교회 안에서만 알릴 내용이면 **방송(OBS) → "유튜브 방송에는 내보내지 않기"**를 체크해 두세요. 예배당 TV에만 나갑니다.

### PPT — ＋ PPT
1. 쓰던 **.pptx** 파일을 고르면 슬라이드마다 **글자·표·그림이 원래 자리대로** 들어옵니다.
2. ✎ 편집에서
   - 글자 칸을 고쳐 쓰고,
   - 그림은 [그림 바꾸기]·[그림 삭제],
   - 표는 칸을 `|` 로, 줄을 줄바꿈으로 구분해 고칩니다.
3. 애니메이션과 화면 전환 효과는 가져오지 않습니다. 제목·본문 칸 위치가 원본과 조금 다를 수 있으니 한 번 훑어보세요.
4. 오래된 .ppt 파일은 파워포인트·키노트에서 **.pptx로 다시 저장**한 뒤 가져오세요.

### PDF·악보 — ＋ PDF·악보
1. **PDF** 또는 **악보 사진**(jpg·png, 여러 장 한 번에)을 고릅니다.
2. 선택 사항
   - **한 페이지 나누기**: 악보는 **"위·아래 2칸"**을 권합니다. 세로로 긴 A4 악보를 TV(가로 화면)에서 크게 볼 수 있습니다. 나눈 칸 사이는 조금 겹치게 잘라 악보 줄이 끊기지 않습니다. 주보·문서는 "나누지 않음".
   - **흰 여백 잘라내기**: 켜 두면 종이 여백을 잘라 더 크게 보입니다.
   - **배경색**: 악보는 흰색, 어두운 자료는 검정.
3. [가져오기]. PDF는 페이지마다, 사진은 장마다 슬라이드가 됩니다.

> 악보·PDF 슬라이드는 **예배당 화면에만** 나가고, 유튜브 방송 자막에는 나가지 않습니다.

### 배경 사진·영상 — 🖼 미디어
1. **🖼 미디어 → ＋ 사진·영상 올리기**로 파일을 올립니다. (jpg·png·gif·webp·mp4·mov·webm 등)
2. 자료 편집 창에서 🖼(한 장) 또는 **모든 슬라이드 배경 → 배경 선택**(전체)으로 지정합니다.
3. 영상 배경은 **소리 없이 반복 재생**됩니다.

> 음악 파일도 올릴 수는 있지만, 예배 중 재생하는 기능은 아직 없습니다.

## 6. 예배 순서 만들기

왼쪽 위 **예배 순서**에서 오늘 예배에 쓸 자료를 차례대로 모아 둡니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 자료를 순서에 넣기 | 자료실에서 자료에 마우스를 올리고 **＋** |
| 순서 바꾸기·빼기 | 순서 항목에 마우스를 올리고 **↑ ↓ ✕** (자료는 자료실에 남음) |
| 새 예배 만들기 (수요예배 등) | 맨 위 **＋** → 이름·날짜 입력 |
| 이름·날짜 바꾸기 / 지우기 | **✎** / **🗑** |
| 다른 예배로 바꾸기 | 맨 위 목록에서 선택 |

## 7. 주일 예배 진행하기

### ① TV·프로젝터 연결
1. 노트북을 HDMI로 TV에 연결합니다.
2. 화면을 **"확장"**으로 둡니다. (**"미러링(복제)"이 아닙니다**)
   - 맥: 시스템 설정 → 디스플레이 → TV를 "확장 디스플레이"로
   - 윈도우: **윈도우 키 + P** → **확장**
3. 운영 화면에서 **📺 예배당 화면 열기**.
4. 열린 창을 **TV 쪽으로 끌어다 놓고 F 키** (전체화면). 더블클릭해도 전체화면이 됩니다.
   - 마우스 커서는 이 화면에서 보이지 않습니다.
   - 다시 F 키를 누르면 전체화면이 풀립니다.

### ② 자막 넘기기
- **슬라이드를 클릭**하면 바로 TV와 유튜브에 나갑니다.
- 오른쪽 미리보기로 지금 나가는 화면을, 아래 **다음 슬라이드** 칸으로 다음 내용을 확인하세요.

### ③ 단축키 (운영 화면에서)
| 키 | 하는 일 |
|---|---|
| **→**  **Space**  **↓**  **PageDown** | 다음 슬라이드 |
| **←**  **↑**  **PageUp** | 이전 슬라이드 |
| **1 ~ 9** | 지금 고른 자료의 1~9번째 슬라이드로 바로 |
| **B** | 검은 화면 (켜고 끄기) |
| **C** | 글자만 지우기. 배경 사진·영상은 남음 (기도 시간 등) |
| **L** | 로고 화면 (⚙︎ 설정에서 로고를 정해 둔 경우) |
| **Esc** | 모두 끄기. 검은 화면·로고를 풀고 글자를 지움 |
| **O** | 방송(유튜브) 자막만 끄기·다시 켜기. 예배당 TV에는 그대로 나감 ([8장](#8-유튜브-생중계에-자막-얹기-obs)) |

> 무선 프레젠터(슬라이드 넘기개)는 대부분 PageDown·PageUp 키를 보내므로 그대로 쓸 수 있습니다.

### ④ 설교자·인도자용 프롬프터
**🎤 프롬프터 열기** → 강대상 모니터 등으로 옮기고 F 키. 지금 나가는 글자를 크게, 다음 슬라이드, 현재 시각, 송출 상태(송출 중·검은 화면·글자 지움)를 보여 줍니다.

## 8. 유튜브 생중계에 자막 얹기 (OBS)

### 8-1. 방송은 이렇게 나갑니다
**예배 실황(카메라 영상)은 OBS가 유튜브로 내보냅니다.** 예배송출은 영상을 직접 방송하지 않고, OBS에 **투명한 자막 화면만** 넘겨줍니다.

```
카메라 ──────────────▶ OBS ──▶ 유튜브 생중계
                        ▲      (카메라 영상 + 자막)
예배송출 ─ 투명 자막 ───┘
   │
   └──── HDMI ──▶ 예배당 TV·프로젝터 (가사·말씀·악보 크게)
```

| 프로그램 | 하는 일 |
|---|---|
| **OBS** (무료, obsproject.com) | 카메라 영상과 소리를 받아서, 그 위에 예배송출 자막을 얹고, 유튜브로 내보냄. 방송 시작·종료도 OBS에서 |
| **예배송출** | 자막 만들기·넘기기, 예배당 TV 화면, OBS로 보낼 투명 자막 화면 |

- OBS는 **운영 노트북에서 함께** 돌려도 되고, **방송용 컴퓨터를 따로** 두어도 됩니다. 노트북 성능이 넉넉하지 않으면 따로 두는 편이 안정적입니다.
- "캡처 장비가 필요 없다"는 말은 **자막을 OBS로 보낼 때** 장비가 필요 없다는 뜻입니다. 카메라를 컴퓨터에 연결할 때는 카메라 종류에 따라 장치가 필요할 수 있습니다. (아래 8-2)

**자막은 양쪽에 함께 나갑니다**
슬라이드를 한 번 클릭하면 **같은 내용이 두 곳에 동시에** 나갑니다. 모양만 다릅니다.

| | 예배당 TV (HDMI) | 유튜브 (OBS) |
|---|---|---|
| 모양 | 화면 가득 큰 글자, 배경 사진·영상 | 카메라 화면 아래쪽의 작은 자막 바 |
| 악보·PDF | 나감 | 나가지 않음 (글자만) |
| 검은 화면(B)·글자 지우기(C)·모두 끄기(Esc) | 적용 | 함께 적용 |
| 🎥 방송 자막 끄기(O) | 그대로 나감 | 꺼짐 |
| "방송에 내보내지 않기"로 정한 자료 | 나감 | 나가지 않음 |

**유튜브에만 자막을 끄고 싶을 때** (기도 제목, 교회 내부 광고 등)
- **잠깐 끄기**: 운영 화면 오른쪽의 **🎥 방송 자막 끄기** 버튼 또는 **O** 키. 다시 누르면 켜집니다. 꺼져 있는 동안 "방송 자막 (OBS)" 미리보기 옆에 빨간 글씨로 **꺼짐**이 표시되고, 프롬프터에도 "방송 자막 꺼짐"이 나옵니다. 끄기는 다시 켤 때까지 유지되니, 다음 순서 전에 꼭 다시 켜세요.
- **이 자료는 늘 끄기**: 자료 편집 창의 **방송(OBS) → "유튜브 방송에는 내보내지 않기"**를 체크하고 저장합니다. 그 자료를 띄울 때만 자동으로 유튜브 자막이 꺼지고, 다른 자료로 넘어가면 다시 나갑니다. 목록에 **TV만** 표시가 붙습니다.

> 팁: 카메라에 예배당 TV 화면이 크게 잡히면, 유튜브에서는 자막이 두 번(TV 속 자막 + 아래 자막 바) 보입니다. 카메라를 강대상 중심으로 잡거나, 자막 스타일에서 방송 자막 위치를 위쪽으로 바꿔 보세요.

### 8-2. 카메라 연결하기
| 카메라 | 연결 방법 |
|---|---|
| **USB 웹캠** | USB에 꽂으면 바로 OBS에서 보입니다. 추가 장치가 필요 없습니다. |
| **캠코더·미러리스·DSLR** (HDMI 출력) | 카메라 HDMI → **캡처 장치**(USB 캡처 동글·캡처 카드) → 컴퓨터 USB. 카메라에 "USB 웹캠 모드"가 있으면 캡처 장치 없이 USB로 바로 연결되기도 하니 먼저 확인해 보세요. |
| **아이폰** (맥) | 맥의 "연속성 카메라"로 아이폰을 웹캠처럼 쓸 수 있습니다. 거치대에 고정해 두세요. |

OBS에서 카메라 넣기: **소스 ＋ → 비디오 캡처 장치** → 카메라(또는 캡처 장치)를 고릅니다.

**소리**: 강단 마이크·찬양 소리는 교회 **음향 믹서의 출력**을 컴퓨터 오디오 입력(또는 USB 오디오 인터페이스)으로 넣으세요. OBS의 오디오 믹서에서 소리 크기가 움직이는지 확인합니다. 카메라 내장 마이크만 쓰면 예배당 울림 때문에 소리가 멀게 들립니다.

### 8-3. 유튜브 연결하기 (처음 한 번)
1. 유튜브 채널에서 **실시간 스트리밍을 사용 설정**합니다. (YouTube Studio → 만들기 → 라이브 스트리밍 시작) 처음 신청하면 사용할 수 있게 되기까지 **최대 24시간**이 걸릴 수 있으니 미리 해 두세요.
2. OBS **설정 → 방송** → 서비스를 **YouTube** 로 고르고 **[계정 연결]**, 또는 YouTube Studio에 나오는 **스트림 키**를 붙여넣습니다.

### 8-4. 예배송출 자막 얹기
1. 운영 화면 **🎥 OBS 자막 주소**를 눌러 주소를 **[복사]** 합니다. (예: `http://192.168.0.10:5300/overlay`)
   - OBS를 **운영 노트북에서 함께** 돌린다면: `http://localhost:5300/overlay`
2. OBS에서 **소스 ＋ → 브라우저**를 추가합니다.
3. **URL**에 주소를 붙여넣고, **너비 1920, 높이 1080**으로 둡니다.
4. 소스 목록에서 브라우저 소스를 **카메라 소스보다 위로** 올립니다. (위에 있는 소스가 화면 앞에 보입니다)
5. 운영 화면에서 슬라이드를 클릭해 OBS 화면에 자막이 나오는지 확인합니다.

한 번 설정해 두면 OBS가 기억하므로, 다음 주부터는 다시 할 필요가 없습니다.

### 8-5. 주일 방송 순서
1. 카메라·음향 연결 → **OBS 켜기** → 카메라 화면과 소리 확인
2. **예배송출 켜기** → 슬라이드 하나를 띄워 OBS에 자막이 나오는지 확인 → **Esc**로 자막 끄기
3. 예배 시작 5~10분 전 OBS에서 **[방송 시작]**
4. 예배 중에는 예배송출에서 자막만 넘깁니다.
5. 예배가 끝나면 OBS에서 **[방송 중단]** → 예배송출 **⏻ 종료**

### 알아 둘 점
- 방송 컴퓨터는 맥이든 윈도우든 상관없습니다. 운영 노트북과 **같은 공유기(와이파이)**에만 연결되어 있으면 됩니다.
- 방송 자막에는 **글자만** 나갑니다. 배경 사진·영상과 악보는 나가지 않습니다.
- 자막 모양은 🎨 자막 스타일 → 오른쪽 "방송 자막"에서 바꿉니다.
- 공유기가 바뀌면 주소(숫자)도 바뀔 수 있습니다. 자막이 안 나오면 주소를 다시 복사해 넣으세요.

## 9. 주중에 미리 준비하기 (웹 편집기)

집이나 사무실 컴퓨터(윈도우도 됨) 브라우저에서 곡·말씀·광고·PPT·예배 순서를 미리 준비합니다.

1. 운영 노트북에서 예배송출을 **켜 둡니다**.
2. 🎥 OBS 자막 주소 창에 적힌 **웹 편집기 주소**와 **PIN**을 확인합니다. (예: `http://192.168.0.10:5300/editor`)
3. 다른 컴퓨터 브라우저에 주소를 넣고 PIN을 입력합니다.
4. 운영 화면과 같은 방식으로 준비합니다. 저장하면 운영 노트북에도 **바로** 반영됩니다.

- 웹 편집기에서는 **송출 버튼이 없습니다.** 화면 송출은 운영 노트북에서만 할 수 있습니다.
- 같은 공유기(와이파이)에 연결된 컴퓨터에서만 접속됩니다.
- PIN을 **5번 틀리면 5분 동안** 잠깁니다.

## 10. 백업·컴퓨터 옮기기·업데이트

### 자료가 저장되는 곳
| 컴퓨터 | 폴더 |
|---|---|
| 맥 | `~/Library/Application Support/WorshipCaster` (Finder → 이동 → 폴더로 이동에 붙여넣기) |
| 윈도우 | `%APPDATA%\WorshipCaster` (탐색기 주소창에 붙여넣기) |

이 폴더 안에 곡·예배 순서·스타일·설정(`db.json`), 올린 사진·영상(`media`), 가져온 성경 텍스트(`bible`)가 있습니다.

- **백업**: 프로그램을 끄고 이 폴더를 통째로 USB나 클라우드에 복사하세요.
- **새 컴퓨터로 옮기기**: 새 컴퓨터에 예배송출을 설치하고 한 번 켰다 끈 뒤, 백업한 폴더 내용으로 바꿔 넣습니다.
  - 성경 폴더를 연결했었다면 새 컴퓨터에서 경로가 달라질 수 있으니 ⚙︎ 설정에서 다시 연결하세요.
- **업데이트**: 새 버전을 받아 앱(또는 폴더)만 바꾸면 됩니다. 자료는 그대로 남습니다.

## 11. 이럴 땐 이렇게 (문제 해결)

**처음 실행할 때 경고창이 떠요**
→ 무료 프로그램이라 나오는 안내입니다. [2. 설치하기](#2-설치하기)의 방법대로 처음 한 번만 허용하세요.

**TV에 노트북 화면이 똑같이 나와요 / 자막 창이 TV로 안 가요**
→ 화면이 "미러링"으로 되어 있습니다. "확장"으로 바꾸세요. ([7장 ①](#7-주일-예배-진행하기))

**TV에서 화면 위아래(양옆)에 검은 띠가 생겨요**
→ 화면을 16:9 비율로 맞추기 때문입니다. TV·프로젝터의 화면 비율 설정을 16:9로 두세요.

**OBS에 자막이 안 보여요**
1. 운영 화면에서 슬라이드를 하나 클릭했는지 (아무것도 안 띄우면 투명합니다)
2. 브라우저 소스가 카메라 소스 **위에** 있는지
3. 방송 컴퓨터와 운영 노트북이 같은 공유기에 있는지
4. 주소가 바뀌지 않았는지 (🎥 OBS 자막 주소에서 다시 복사)
5. 운영 노트북의 방화벽에서 예배송출(윈도우는 node)이 **허용**되어 있는지

**웹 편집기에 접속이 안 돼요**
→ 운영 노트북이 켜져 있고 예배송출이 실행 중인지, 같은 와이파이인지 확인하세요. 학교·회사처럼 기기끼리 접속을 막는 와이파이에서는 안 될 수 있습니다.

**성경을 못 찾는다고 나와요**
→ ⚙︎ 설정에서 성경을 연결했는지 확인하세요. 그 번역본에 해당 장이 있는지, 책 이름이 맞는지(`요`, `요한복음`, `John`) 확인하세요.

**글꼴이 설정과 다르게 보여요**
→ 인터넷이 없으면 본고딕(Noto Sans KR) 대신 컴퓨터의 기본 한글 글꼴로 보입니다. 예배 진행에는 문제없습니다.

**프로그램을 껐는데 다시 안 켜져요 / 이상하게 동작해요**
→ 컴퓨터를 한 번 다시 시작해 보세요. 그래도 안 되면 기록 파일을 함께 보내 주세요.
- 맥: `~/Library/Logs/WorshipCaster.log`
- 윈도우: 작업 표시줄의 WorshipCaster 창에 나온 글

## 12. 저작권 안내

- **성경**: 개역개정·새번역·현대인의성경과 ESV·NIV·NLT 등은 저작권이 있는 번역본입니다. 예배당 화면이나 유튜브로 내보내기 전에 교회가 사용 허가를 받았는지 확인하세요. 개역한글은 저작권이 만료되었습니다.
- **찬양 가사·악보**: 곡마다 저작권이 있습니다. 특히 유튜브 생중계·다시보기에 가사를 띄울 때는 교회가 필요한 이용 허락을 받았는지 확인하세요.
